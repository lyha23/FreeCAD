## 执行顺序

1. S0 冻结 C9-M2 关闭状态、live capability 和 forbidden claims。
2. S1 复核 FreeCAD / cad-core / tests / fixtures source authority。
3. S2 把每个 scope 路由到 oracle、backendGap、releaseGate 或 nonGoal。
4. S3 处理 `PointCurve`，不得把它和全 default branch 混成一个单点修复。
5. S4 批量处理 default planar branch：已有 expected 先激活，缺 expected 先采集或保留 `notCollected`。
6. S5 审核 capability 与 diagnostics，不允许 adapter 字符串隐藏 runtime 缺口。
7. S6 根据 S3-S5 结果落 C++ 或 release gate。
