## 分类规则

| 状态 | 使用条件 | 下一步 |
| --- | --- | --- |
| `native_oracle_required` | 需要 FreeCADCmd / native probe 证明行为 | 交 S3。 |
| `product_decision_required` | native 行为可见但 DTO 是否允许需要产品边界 | 交 S4。 |
| `known_gap_retained` | full cache 仍依赖 temporary document 或不可序列化 state | 交 S5/S6 保持 diagnostic。 |
| `backend_gap_candidate` | 可能有 request-local DTO，但证据不足 | S3/S4 前不得落代码。 |
| `diagnostic_non_goal` | GUI/session/cache/downstream 等明确排除 | 写 non-goal registry。 |
| `release_gate` | capability、diagnostic、test、docs 发布一致性 | 交 S5/S6。 |

`backend_gap_requires_implementation` 只允许 S5/S6 在 S3 native evidence 与 S4 产品边界同时成立后生成；S2 当前没有这两类证据，因此只保留 candidate / review / release 路由。
