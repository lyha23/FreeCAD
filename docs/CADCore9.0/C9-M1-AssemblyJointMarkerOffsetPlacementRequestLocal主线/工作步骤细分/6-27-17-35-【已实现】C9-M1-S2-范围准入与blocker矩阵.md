# 【已实现】C9-M1 S2 范围准入与 blocker 矩阵

## 目标

把 Assembly marker / placement 方向拆成可裁决 scope：existing covered marker path、non-identity `offsetPlc`、non-AssemblyLink primitive frame、solver writeback、capability publication、persistent solver session non-goal。

## 分类规则

- `already_covered`: current source / tests / expected 已覆盖，S6 只需发布或回归。
- `oracle_candidate`: 需要 FreeCAD native expected 或 probe，不能直接进入 C++ 实现。
- `backend_gap_candidate`: 有 FreeCAD source authority 且 current cad-core 可能 mismatch，可在 S6 进入受限实现。
- `known_gap_retained`: 语义存在但证据不足或上游 oracle 阻塞。
- `diagnostic_non_goal`: 违反无状态 CAD Core 或属于 GUI/session/persistent state。
- `release_gate`: 只需 capability/docs/tests 发布收口。

## 必须回写

- `C9M1-SCOPE-101` 到 `C9M1-SCOPE-304`
- `C9M1-BG-101` 到 `C9M1-BG-501`
- `C9M1-NG-001` 到 `C9M1-NG-008`
- `C9M1-BLOCKER-201`

## S2 结论

- `scope_review_matrix` 已从 `initial_route` 调整为 S2 `route` 裁决表；`C9M1-SCOPE-101..304` 均有 owner step、route 和 close condition。
- route 分布：`already_covered` 覆盖 current marker subset、request-local placement writeback、unsupported diagnostics；`oracle_candidate` 覆盖 non-identity bundled `offsetPlc`；`known_gap_retained` 覆盖 zero Angle fallback class evidence；`diagnostic_non_goal` 覆盖 non-AssemblyLink primitive frame、persistent solver session 和完整 Link / ShowElement lifecycle；`release_gate` 覆盖 capability publication 和 focused release validation。
- `backend_gap_classification` 已为 `C9M1-BG-101..501` 写入 route 和 close condition；`non_goal_registry` 已为 `C9M1-NG-001..008` 写明 scope 或 exclusion reason。
- `C9M1-BLOCKER-201` 已关闭为 `Closed S2`；S3-S6 只消费这些 route，不在 S2 实现代码、采 heavy/native oracle、新增 fixture 或改变 capability supported 声明。
