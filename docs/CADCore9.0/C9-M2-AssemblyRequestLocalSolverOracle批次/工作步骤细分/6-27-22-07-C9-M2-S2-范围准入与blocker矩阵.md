# C9-M2 S2 范围准入与 blocker 矩阵

## 目标

把 C9-M2 批次拆成可裁决 scope：bundled `offsetPlc` object marker、subshape marker、writeback，custom placement-chain expected activation，zero Angle fallback native oracle，diagnostic guard，capability publication 和 final release gate。

## 分类规则

- `native_oracle_required`: 必须采 FreeCAD expected 才能判断实现与否。
- `expected_activation`: expected 已存在但缺 focused test 约束。
- `backend_gap_candidate`: native oracle 与 current cad-core mismatch 同时存在，可在 S6 进入受限实现。
- `already_covered_review`: current source / tests / expected 可能已覆盖，需要复核后关闭。
- `known_gap_retained`: 有 source evidence 但缺 stable oracle 或非本轮采集。
- `diagnostic_non_goal`: 违反 stateless CAD Core 或缺产品 DTO。
- `release_gate`: 只需 capability/docs/tests 发布收口。

## 必须回写的矩阵行

- `C9M2-SCOPE-101` 到 `C9M2-SCOPE-304`
- `C9M2-BG-101` 到 `C9M2-BG-601`
- `C9M2-NG-001` 到 `C9M2-NG-006`
- `C9M2-BLOCKER-201`
