## 执行顺序

1. S0 冻结 C9-M1 关闭状态、live capability 和 forbidden claims。
2. S1 复核 FreeCAD / cad-core / tests / fixtures source authority。
3. S2 把每个 scope 路由到 oracle、backendGap、releaseGate 或 nonGoal。
4. S3 批量采集 bundled `offsetPlc` oracle，不允许只采一个 case 就关闭。
5. S4 激活 existing custom placement-chain expected，避免 oracle 未进入测试面。
6. S5 采集或保留 zero Angle fallback，并验证 diagnostics 不被静默改成 success。
7. S6 根据 S3-S5 结果落 C++ 或 no-code release gate。
