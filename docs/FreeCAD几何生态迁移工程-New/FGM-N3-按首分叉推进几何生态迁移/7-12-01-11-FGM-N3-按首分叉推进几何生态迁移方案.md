# FGM-N3 按首处分叉推进几何生态迁移方案

## 目标

N1/N2 完成后，把 CAD Core 的迁移工作从“最终 response 哪里不同”改成“哪个 producer scope 的哪个 checkpoint 第一次不同”。每个实现批次以一条完整 FreeCAD 调用链为最小语义单元，在正确的 `app`、`part`、`sketcher` 或 `part_design` 模块修复，最后再验证 public parity。

本文件只定义迁移循环，不提前声明任何 geometry family 已实现。

## 固定循环

1. 从 native role manifest 选择一个最小完整 producer family，不按单个 FaceN 或单 fixture 打补丁。
2. 用 producer-enabled FreeCADCmd 同次生成 public expected、ledger 与 native trace；三个 artifact 均独立闭包。
3. 用当前 `cad-core` 默认生成 public actual 与 CAD Core trace。
4. N2 比较器只报告第一处分叉：transaction、scope path、slice、decision/reason、before/after checkpoint 与第一个字段路径。
5. 依据 slice-to-module 矩阵读取 FreeCAD 源类/函数，修复同构低层模块；禁止在 runtime/adapter/fixture 中覆盖。
6. 重新运行同一 family。第一处分叉前移或消失才说明取得进展；最终 raw 名偶然相等不算闭环。
7. producer trace 对齐后，再运行 public expected/ledger/release gate，确认对外语义与引用恢复。
8. 删除被正式账本替换的 fallback/synthetic name，更新 capability、矩阵和关闭证据。

## family 顺序

建议按依赖从低到高推进：

| 顺序 | family | 关键切片 | 主要 CAD Core 落点 |
| ---: | --- | --- | --- |
| 1 | StringHasher + ElementMap | `hasher.*`、`element_map.*`、`child_map` | `app/string_hasher.*`、`part/topo_shape.cpp` |
| 2 | TopoShape + raw Mapper | `toposhape.*`、`mapper.*`、`maker.*` | `part/topo_shape*.cpp`、mapper |
| 3 | FaceMaker + WireJoiner + Sketch | split/open wire/SKT checkpoints | `part/face_maker.cpp`、`wire_joiner.cpp`、`sketcher/` |
| 4 | Property + Extrude/Boolean/Refine | slot/setValue/retag/extrude/boolean/refine | `part/`、`part_design/feature_extrude.cpp` |
| 5 | DressUp | base selection/CHF/FLT/refine/final slot | `part_design/feature_dress_up.cpp` 与 Chamfer/Fillet |
| 6 | Pattern/Transform | Originals/instance/K tuple/fuse-cut/slot | `part_design/feature_transformed.cpp` 与 patterns |
| 7 | Body/Tip 与引用恢复 | ledger-only inheritance/reference update | `part_design/body.cpp`、`app` links、runtime dispatch |

上层 family 依赖低层 checkpoint。若 mapper snapshot 已不同，不得先修 Body；若 property handoff 前一致、handoff 后不同，修 property seam，不重写 maker；若 Body 内出现 Pad replay，删除 replay 而不是接受最终 shape 相等。

## 每个迁移 ticket 的最小证据

```text
fixture family / native role
FreeCAD source file + class/function + key branch
expected transaction/scope/slice
actual transaction/scope/slice
first divergent before/decision/field/after path
owner CAD Core module
planned general semantic change
focused tests
public/ledger/trace validation commands
remaining downstream drift
```

没有第一处分叉证据、只有最终 JSON diff 的问题不能进入实现队列。没有 native trace 的 case 先回到 oracle 收集，不得从当前 CAD Core output 反推 FreeCAD 行为。

## 门禁分层

### 本轮短跑

- 构建直接修改的 `cad-core` target；
- 运行对应 recorder/producer focused tests；
- 对本 family 的一个代表 case运行 N2；
- `git diff --check`。

### family 回归

- 同一调用链的成功、guard/failure、preserve/generated/modified、多源与 property handoff case；
- native/actual trace closure；
- public expected/ledger strict comparison；
- 不把未相关 phase 混入普通实现回合。

### 重型收口

- family 代表 case 两次运行确定；
- first-divergence comparator 无缺失/模糊分类；
- public release gate 按当前工具合同通过；
- mutation validator 继续 hard fail；
- 旧 fallback 删除条件满足。

## 非目标

- trace 不成为 CAD Core 建模输入、runtime cache 或新 public schema。
- comparator 不自动修代码、接受差异、更新 expected 或修改 release verdict。
- 不以 raw `#id`、objectTag、event number、fixture 名或 display subname 写业务分支。
- 不把所有 480 个 native case 一次性塞入首个迁移批次；按共享调用链组成最小完整 family，再逐 family 扩展。

## 完成定义

一个 family 只有在 native/actual producer trace 的 required scopes/checkpoints 对齐、第一处分叉消失、public expected/ledger 门禁通过、无副作用与确定性成立、旧 fallback 已清理后才可关闭。N3 的最终目标不是“比较器不报错”，而是让 CAD Core 的业务生产链在正确模块中可解释、可重建、可持续扩展。
