## 执行顺序

S0 -> S1 -> S2 -> S3 -> S4 -> S5 -> S6。后一步只能消费前一步已写入矩阵的合同、authority 和状态结论。S3/S4 需要代码改动时，必须先在步骤文件和矩阵中写清 FreeCAD source authority、CAD Core product-contract 边界、C++ 落点、fixtures/tests 和禁止 shortcut。

## 当前矩阵闸门

- `c6m4_sweep_located_profile_combined_source_candidates.tsv`：S1 负责补强与确认。
- `c6m4_sweep_located_profile_combined_scope_review_matrix.tsv`：S2 冻结 S3-S6 执行范围。
- `c6m4_sweep_located_profile_combined_blocker_queue.tsv`：S3/S4/S5 必须逐行消费，不能跳过 blocker close condition。
- `c6m4_sweep_located_profile_combined_backend_gap_classification.tsv`：只有 FreeCAD authority + current cad-core mismatch 充分时才保留 `backendGap`。
- `c6m4_sweep_located_profile_combined_non_goal_registry.tsv`：Filling、Loft、Groove、GUI、persistent wrapper lifecycle 不能混入本主线。

## 状态纪律

- 单个步骤验收完成后，才允许在该步骤文件名中插入 `【已实现】` 并更新所有链接。
