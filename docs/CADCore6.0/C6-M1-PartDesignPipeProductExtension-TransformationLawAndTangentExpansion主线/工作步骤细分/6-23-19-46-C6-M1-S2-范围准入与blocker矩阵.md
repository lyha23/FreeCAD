# C6-M1 S2 范围准入与 blocker 矩阵

## 目标

把 S1 候选路由到可执行范围：product extension、backendGap、releaseGate、nonGoal 或 blocked-by-contract。S2 不能凭源码存在就创建 backendGap。

## 分类规则

| 状态 | 准入条件 | 下一步 |
| --- | --- | --- |
| `baselineSupported` | C51 已支持且 C6 只回归保护 | S5/S6 regression gate |
| `productExtensionCandidate` | FreeCAD 属性 / 注释可支撑产品扩展，但无 parity claim | S3/S4 定义合同 |
| `productContractRequired` | 没有可执行 FreeCAD path 或字段含义不足 | S3/S4 先定产品合同 |
| `backendGap` | 产品合同清楚且 cad-core 当前未实现 | S6 C++ |
| `releaseGate` | 代码可能已落或待落，但发布需要 capability/docs/tests | S5/S6 |
| `nonGoal` | 本包排除 | non-goal registry |

## blocker 路由

| blocker | 路由 | 原因 |
| --- | --- | --- |
| Law DTO | productContractRequired -> backendGap | 需要 request 字段定义后才能实现。 |
| Linear / S-shape SetLaw | backendGap | FreeCAD 注释块给出低层方向，但发布是 CAD Core extension。 |
| Interpolation | productContractRequired | 只有 enum，没有 FreeCAD law 分支。 |
| continuous-edge ledger | productContractRequired -> backendGap | 必须定义 adjacency / continuity / ordering 账本。 |
| PipeShell history / capability | releaseGate | 需保护已有 C51 PipeShell / MapperSewing 能力。 |

## 必须回写的矩阵行

- `C6M1-SCOPE-201` 到 `C6M1-SCOPE-501`。
- `C6M1-BLK-201` 到 `C6M1-BLK-501`。
- `C6M1-CAT-201` 到 `C6M1-CAT-501`。
- `C6M1-NG-*` 需要全部链接到排除原因。

## 非目标

- 不把 `Interpolation` 偷换为 Linear 或 S-shape。
- 不把 continuous-edge expansion 简化成 compound 全边收集。
- 不修改 source-backed diagnostics。
