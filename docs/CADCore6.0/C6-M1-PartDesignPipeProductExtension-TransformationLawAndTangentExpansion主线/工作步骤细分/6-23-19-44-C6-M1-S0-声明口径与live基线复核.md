# C6-M1 S0 声明口径与 live 基线复核

## 目标

冻结 C6-M1 的声明口径：本包是 CAD Core product extension，不是 FreeCAD parity 修复；只处理 PartDesign Pipe `Transformation=Linear/S-shape/Interpolation` 与 `SpineTangent/AuxiliarySpineTangent`。

## 输入

- C51X follow-up：`docs/CADCore5.1-PartDesign-剩余deferred语义实现/README.md`
- C51X blocker：`docs/CADCore5.1-PartDesign-剩余deferred语义实现/矩阵/cadcore51_followup_blocker_queue.tsv`
- live capability：`cad-core/src/runtime/capability_contract.cpp`
- current executor：`cad-core/src/part_design/feature_pipe.cpp`
- FreeCAD source：`src/Mod/PartDesign/App/FeaturePipe.cpp`、`FeaturePipe.h`

## 声明口径

| 类型 | 口径 |
| --- | --- |
| 必须声明 | C6-M1 是产品扩展；FreeCAD source-commented 分支仍作为依据和边界。 |
| 必须声明 | 当前 cad-core source-backed diagnostics 是基线，不是实现完成证据。 |
| 禁止声明 | FreeCAD 支持 Linear / S-shape / Interpolation law parity。 |
| 禁止声明 | `SpineTangent` 能按 FreeCAD native path 自动扩张 tangent edges。 |
| 禁止声明 | 本包覆盖 GUI Pipe、Part Workbench Sweep wrapper、cross-request PipeShell lifecycle。 |

## 状态词典

| 状态 | 含义 |
| --- | --- |
| `baselineSupported` | C51 已支持，C6 只做回归保护。 |
| `productExtensionCandidate` | FreeCAD 有属性 / 注释依据，但实现只能按 CAD Core 产品合同推进。 |
| `productContractRequired` | 没有可执行 FreeCAD path，必须先定义产品 DTO 和验收语义。 |
| `backendGap` | 产品合同已明确，cad-core 当前代码未实现。 |
| `releaseGate` | 需要 capability、docs、fixtures、tests 同步后才可发布。 |
| `nonGoal` | 本包明确排除，必须写用户行为和 reopen condition。 |

## 必须回写的矩阵行

- `C6M1-SCOPE-000`：live baseline。
- `C6M1-SCOPE-101`：product-extension claim。
- `C6M1-BLK-000`：baseline gate。
- `C6M1-NG-001` 到 `C6M1-NG-005`：禁止声明。
