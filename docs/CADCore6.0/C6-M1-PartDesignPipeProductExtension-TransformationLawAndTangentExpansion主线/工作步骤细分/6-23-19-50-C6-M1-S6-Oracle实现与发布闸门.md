# C6-M1 S6 Oracle 实现与发布闸门

## 目标

消费 S2-S5 留下的 product extension / backendGap / releaseGate，落地 C++、fixtures、focused tests、capability 和 docs。S6 不扩大范围。

## 实施顺序

1. 保留现有 C51 Pipe regression，新增 `cad-core/fixtures/c6m1`。
2. 在 `feature_pipe.cpp` 中把 source-blocked diagnostics 改成合同驱动：未提供 C6 DTO 时仍保留 exact diagnostic，提供 DTO 且合法时进入 product extension。
3. 在 `part/topo_shape_expansion` 或相邻 PipeShell helper 中封装 `PipeScalingLaw` 与 `ContinuousEdgeLedger`，避免 executor 散落 OCCT `Law_*` 细节。
4. 为 Linear / S-shape 增加最小完整语义批次 fixture；Interpolation 已由 S3 裁决为 `product_contract_required` 诊断边界，S6 不实现几何 law。
5. 为 SpineTangent / AuxiliarySpineTangent 增加连续边 ledger fixture、branch diagnostic 和 selected EdgeN regression。
6. 更新 capability product-contract，删除或重写对应 exact blocker 时必须有 focused tests。

- 不按 fixture 名、bbox、volume、edge 数量或输出顺序推断 law / tangent 语义。
