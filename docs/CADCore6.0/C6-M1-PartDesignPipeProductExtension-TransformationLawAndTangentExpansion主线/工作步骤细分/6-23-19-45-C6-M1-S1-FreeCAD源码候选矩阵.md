# C6-M1 S1 FreeCAD 源码候选矩阵

## 目标

用 live FreeCAD / cad-core 源码复核候选，不把候选直接升级为 supported 或 backendGap。

## FreeCAD 依据

| 候选 | 源码 | 证据 |
| --- | --- | --- |
| Pipe 属性 | `src/Mod/PartDesign/App/FeaturePipe.cpp::Pipe::Pipe()` | `SpineTangent`、`AuxiliarySpineTangent`、`Transformation` 属性存在。 |
| Transformation enum | `src/Mod/PartDesign/App/FeaturePipe.cpp::TransformEnums` | enum 暴露 `Linear`、`S-shape`、`Interpolation`。 |
| commented law | `src/Mod/PartDesign/App/FeaturePipe.cpp::Pipe::execute()` | `Law_Linear`、`Law_S` 分支整体注释；`Interpolation` 无执行分支。 |
| commented tangent | `src/Mod/PartDesign/App/FeaturePipe.cpp::buildPipePath()` | `getContinuousEdges(shape, subedge)` 调用被注释。 |
| continuous helper | `src/Mod/PartDesign/App/FeaturePipe.cpp::getContinuousEdges()` | helper 主体整体注释；只能作为设计参考，不是 native parity。 |
| current cad-core blocker | `cad-core/src/part_design/feature_pipe.cpp::rejectSourceBlockedPipeBranches()` | 当前按 `unsupported_property` 拒绝 law / tangent。 |

## 候选 TSV 字段

`candidate_id	source_file	freecad_symbol	semantic_axis	source_evidence	cad_core_landing	scope_hint	next_step`

## 扫描轴

- 属性 / enum 是否存在。
- FreeCAD 执行分支是否可执行。
- cad-core 是否已有 request parse / diagnostic。
- 是否需要新 DTO。
- 是否会影响 PipeShell maker history / MapperSewing。

## 必须回写的矩阵行

- `C6M1-SRC-001` 到 `C6M1-SRC-008`。
- 每条 candidate 必须有 `scope_hint`，但不得直接写 `supported`。

## 验收标准

```bash
cd /home/user/Chili3DProject/FreeCAD
rg -n 'TransformEnums|ScalingData|getContinuousEdges|buildPipePath|SpineTangent|AuxiliarySpineTangent' src/Mod/PartDesign/App/FeaturePipe.cpp src/Mod/PartDesign/App/FeaturePipe.h
rg -n 'rejectSourceBlockedPipeBranches|Transformation.*Linear|SpineTangent is source-blocked' cad-core/src/part_design/feature_pipe.cpp
awk -F '\t' 'NR==1{n=NF} NF!=n{print FILENAME ":" NR ": expected " n " fields, got " NF}' docs/CADCore6.0/C6-M1-PartDesignPipeProductExtension-TransformationLawAndTangentExpansion主线/矩阵/c6m1_pipe_product_extension_source_candidates.tsv
```

通过条件：候选覆盖属性、law、tangent、PipeShell、history、capability；没有 candidate 被直接当成发布能力。
