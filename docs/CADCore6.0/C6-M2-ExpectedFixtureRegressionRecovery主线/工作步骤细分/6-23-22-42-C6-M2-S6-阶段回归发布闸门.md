# C6-M2 S6 阶段回归发布闸门

## 目标

运行 C6-M2 阶段回归，发布 expected fixture recovery 状态。S6 是发布闸门：只有阶段回归通过，或剩余失败都被写成明确 known gap，才能关闭 C6-M2。

## 必读输入

- S0-S5 已实现文档
- `矩阵/c6m2_expected_fixture_regression_validation_matrix.tsv`
- `矩阵/c6m2_expected_fixture_regression_blocker_queue.tsv`
- `docs/CADCore6.0/README.md`
- 相关 capability / docs 状态文件

## 实施内容

1. 运行 focused expected fixture test。
2. 运行阶段回归：

   ```bash
   cd /Users/li/Chili3DProject/FreeCAD/cad-core
   python3 -m unittest tests.test_p7_features tests.test_expected_fixtures tests.test_adapters
   ```

3. 若修改 topo/history、ShapeFix、assembly solver adapter 或 shared recompute schema，补跑重型收口命令。
4. 更新本主线总入口、README、validation matrix 和 blocker queue。
5. 若通过，将 S0-S6 均标记为 `【已实现】`，并在 `docs/CADCore6.0/README.md` 写 C6-M2 完成状态。
6. 若仍有失败，只能关闭已证实的部分；剩余必须是 known gap，带 owner、删除条件和下一步路径。

## 非目标

- 不为了发布而隐藏 failure。
- 不把 known gap 写成 supported。
- 不把 Pipe Interpolation 几何合同混入发布。
