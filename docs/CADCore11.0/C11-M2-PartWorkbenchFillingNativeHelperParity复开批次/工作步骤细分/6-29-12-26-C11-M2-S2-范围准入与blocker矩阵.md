# C11-M2 S2 范围准入与 blocker 矩阵

## 目标

把 S1 source candidates 路由到 scope、blocker、oracle fixture、non-goal 和 backend gap 分类。S2 的核心闸门是：没有 stable native oracle 之前，不允许出现 implementation-ready backend gap。

## 分类规则

| 状态 | 含义 | owner |
| --- | --- | --- |
| `baseline_frozen_pending_s0` | live 状态需要 S0 确认。 | S0 |
| `source_authority_pending_s1` | 只证明源码路径，不证明可采 oracle 或 support。 | S1 |
| `native_oracle_pending_s3` | 需要 FreeCADCmd 复采集才能决定 stable / notCollected。 | S3 |
| `current_product_comparison_pending_s4` | C6-M5 current product contract 可作为 comparison target，但依赖 S3 stable oracle。 | S4 |
| `nonGoal_pending_s5` | 协议外、UI、wrapper lifecycle 或 shortcut 行。 | S5 |
| `release_gate_pending_s6` | S3-S5 以后才决定 no-code gate 或 code gate。 | S6 |

- Supports/Orders C0/G1/G2 helper oracle。

- Non-boundary edge/wire/face/vertex support/order helper oracle，同时保留 C5-M12 no-support/order expected-backed subset。
