# C11-M2 S6 Oracle 实现与发布闸门

## 目标

消费 S3-S5 结果，决定 C11-M2 是 no-code retained non-parity release gate，还是进入 C++ / fixtures / focused tests / capability 的实现 gate。S6 不得在没有 stable native oracle 与 S4 mismatch 的情况下改代码。

## 进入 S6 的合法输入

- `notCollected`: 保留为 diagnostic / historical evidence，不创建 backend gap。
- `stable_native_expected`: 可以进入 S4 comparison；若 current cad-core mismatch，进入 S6 implementation。
- `backend_gap_candidate`: 必须有 S4 写明 native expected、current output、FreeCAD source authority、test route 和禁止 shortcut。
- `nonGoal_closed`: 只能作为 release boundary，不得落代码。
- `releaseGate`: 发布 docs / capability / tests 状态。
