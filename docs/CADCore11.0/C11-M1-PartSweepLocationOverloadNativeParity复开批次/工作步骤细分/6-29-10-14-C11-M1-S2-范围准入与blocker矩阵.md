# C11-M1 S2 范围准入与 blocker 矩阵

## 目标

把 S0/S1 的 source candidates 路由到 scope、blocker、nonGoal 和 backend gap classification。S2 的核心判断是：哪些只是 source authority，哪些可以进入 native oracle 复采集，哪些必须保留 non-goal，哪些只有在 S4 后才可能成为 implementation row。

## 分类规则

| 状态 | 使用条件 |
| --- | --- |
| `baseline_frozen` | live capability / dirty boundary / queue 状态已冻结。 |
| `source_only` | 只有源码或 wrapper 签名，尚无 native observable expected。 |
| `notCollected_reopen_candidate` | historical blocker 有 delete condition，可复采 oracle，但还不能改 C++。 |
| `current_product_contract` | cad-core 已有 C6-M4 product path，可作为 comparison target。 |
| `backend_gap_candidate` | S3 有 stable native oracle，S4 证明 current mismatch，且语义能落到 request-local CAD Core。 |
| `diagnostic_retained` | oracle 不可采或协议边界不可落地，只保留 diagnostic / non-parity。 |
| `nonGoal` | GUI、persistent wrapper lifecycle、PartDesign Pipe/Hole、adapter 修剪或 fixture 特判。 |

## 必须回写的矩阵行

- `C11M1-SCOPE-001,101,102,103,104,201,301`
- `C11M1-BLOCKER-201,301,302,401,501,601`
- `C11M1-NG-001..007`
- `C11M1-CAT-101..105`
