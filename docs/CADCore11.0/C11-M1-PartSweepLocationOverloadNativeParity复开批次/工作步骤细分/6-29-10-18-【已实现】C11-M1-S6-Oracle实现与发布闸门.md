S6 消费 S3-S5 后关闭为 no-code retained non-parity release gate：

- S3 reconfirmed：FreeCADCmd `1.2.0 revision 20260519` / OCCT `7.8.1`
  下，located overload 代表性 case 在 `is_ready_before_build=true` /
  `status_before_build=0` 后于 `builder.build()` 返回
  `OCCError: NCollection_Array1::Value`；没有 stable native `shape_summary`。

  comparison target 和 product-contract evidence；因为没有 stable native oracle 或
  `cad-core/fixtures/c11m1` expected，不能做 parity comparison，也不能生成
  `backend_gap_candidate`。

  lifecycle、adapter 修剪、PartDesign Pipe/Hole 内部 PipeShell、fixture-name/bbox/area
  /output-order 修复，以及无 oracle 时把 C6-M4 product contract 升级为 parity，均已关闭为 non-goal。
- 当前 `cad-core/src/runtime/capability_contract.cpp` 与
  `cad-core/tests/test_adapters.py` 继续发布
  `supported_multi_profile_linearize_c6m4_product_contract_non_parity`、
  `freecadcmd_location_overload_status=notCollected`、两个 narrowed wrapper blocker
  和 `part_workbench.sweep.remaining_gaps=[]`。S6 不修改 capability，只发布本批次
  no-code release gate。

`closed_s6_no_code_retained_non_parity_release_gate`；`C11M1-SCOPE-201` 和
`C11M1-CAT-105` 同步关闭为 S6 no-code publication。未来 reopen 条件保持不变：
