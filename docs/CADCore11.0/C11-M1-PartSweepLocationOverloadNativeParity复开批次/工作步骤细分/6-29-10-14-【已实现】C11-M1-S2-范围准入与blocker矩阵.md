## 分类规则

| 状态 | 使用条件 |
| --- | --- |
| `baseline_frozen` | live capability / dirty boundary / queue 状态已冻结。 |
| `source_only` | 只有源码或 wrapper 签名，尚无 native observable expected。 |
| `notCollected_reopen_candidate` | historical blocker 有 delete condition，可复采 oracle，但还不能改 C++。 |
| `current_product_contract` | cad-core 已有 C6-M4 product path，可作为 comparison target。 |
| `backend_gap_candidate` | S3 有 stable native oracle，S4 证明 current mismatch，且语义能落到 request-local CAD Core。 |
| `diagnostic_retained` | oracle 不可采或协议边界不可落地，只保留 diagnostic / non-parity。 |
| `nonGoal` | GUI、persistent wrapper lifecycle、PartDesign Pipe/Hole、adapter 修剪或 fixture 特判。 |

- `C11M1-SCOPE-001` 保持 `baseline_frozen`；`C11M1-SCOPE-101` 只保留 `source_only`，不升级为 supported。
- `C11M1-SCOPE-102` 与 `C11M1-SCOPE-104` 路由为 `notCollected_reopen_candidate`，只进入 S3 native oracle 复采集。
- `C11M1-SCOPE-103` 与 `C11M1-SCOPE-201` 只作为 `current_product_contract` / release publication comparison target，不能在 S2 生成 backend gap。
- `C11M1-SCOPE-301` 路由为 `nonGoal`，覆盖 GUI、persistent wrapper lifecycle、PartDesign Pipe/Hole、adapter trimming 和 fixture-name/bbox/output-order fixups。
- `C11M1-BLOCKER-201` 已关闭为 `closed_s2_scope_routing_complete`；`C11M1-BLOCKER-301/302/401/501/601` 保持后续步骤 pending，且都有 scope ID、required evidence 和 close condition。
