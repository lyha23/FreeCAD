## 完成口径

Assembly 4.0 rows 有明确 source/fixture/diagnostic/capability；fallback 与 real solver 状态不混淆。

## 完成记录

- JointType 审计：`JointObject.py::JointTypes` 的 13 类保持为目标内矩阵；C4-S10 不新增 FreeCAD 外 JointType。
- Validation / diagnostics：新增 c4m5 `missing_grounded_part`、PointCurve `unsupported_assembly_solver` 和 partial writeback fixtures；`ondsel_solver_failed` 保持真实 adapter exception diagnostic；`invalid_assembly_solver_result` 记录为 FreeCAD drag `validateNewPlacements()` 边界，不改写 recompute `solve()` native path。
- Writeback 生命周期：`documentObjectUpdates.action=assembly_set_placement` 仍是 request-local 建议，前端 DocumentObject graph 是唯一真实数据；partial writeback 只更新变更 component。
- Capability：`representative_solver_adapter.status=covered_representative` 且 `mode=fallback_metadata_only`，不作为 full Ondsel solver。
