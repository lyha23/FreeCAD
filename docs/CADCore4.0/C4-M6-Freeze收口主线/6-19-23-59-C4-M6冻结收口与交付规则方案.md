# C4-M6 冻结收口与交付规则方案

## 目标

C4-M6 是 4.0 freeze 阶段，只做同步、验证、发布和边界清理，不新增大语义。

## 收口对象

- 4.0 capability matrix。
- 4.0 oracle / fixture queue。
- `cad_core_capabilities_json()` metadata。
- expected fixtures 与 known diagnostic policy。
- focused tests 与阶段回归命令。
- 文档中的 remaining boundary、non-goal、next owner。

## 完成判定

| 项 | 判定 |
| --- | --- |
| scope | 每个 4.0 任务都有 FreeCAD 源码依据、cad-core 落点和验收证据 |
| capability | 不保留 broad gap；未完成项拆成 feature-family / lifecycle / producer / adapter contract |
| fixture | 成功路径、失败 diagnostic、known deferred 都有 expected 或文档边界 |
| topo naming | 不用输出修剪、fixture 名称或几何猜测替代 MapperHistory / ElementMap |
| adapter | CLI / C ABI / Worker / WASM schema parity；adapter 不承载建模语义 |
| docs | 已实现方案加 `【已实现】`；未实现方案保留清晰 next owner |

## 非目标

- 不在 freeze 阶段临时扩大实现范围。
- 不因为某个 fixture 失败就直接放宽 expected 或改输出端。
- 不把当前机器的非 expected 采集基线 OCCT 差异当成 FreeCAD 语义变更。
