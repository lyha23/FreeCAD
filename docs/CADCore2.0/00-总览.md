# CAD Core 2.0 总览

## 目标

CAD Core 2.0 的目标是把当前 `cad-core` 从“可跑大量 FreeCAD 风格 fixture 的独立内核原型”推进到“可支撑前端长期编辑、稳定引用更新和常用 PartDesign / Part / Link 工作流的无状态几何内核”。

2.0 不追求复刻完整 FreeCAD GUI、Workbench、ViewProvider、TaskPanel 或跨请求文档会话。2.0 只抽取 FreeCAD 几何建模核心语义，并保持当前无状态 CAD Core 边界。

## 当前基线

当前已落地：

- `document / graph / runtime` 底座。
- FreeCAD 风格 `Objects[] / Name / ID / TypeId / Properties` 输入。
- Sketch + Body + Pad / Pocket / FeatureExtrude / FeatureBase 主链。
- typed property、`PropertyLink*`、placement、基础 GeoFeatureGroup。
- Sketcher profile、基础约束、ExternalGeometry 子集、InternalShape 子集。
- `NamedShape / ElementMap` 主路径骨架、stable subname 引用更新、ReferenceShadow 恢复子集。
- Datum / Origin、RefineModel 子集、Hole 常用孔、Fillet / Chamfer、Transformed family 基础路径。
- Part primitives、导入导出、常用 Part Boolean。
- 基础 Link / LinkSub / LinkGroup / LinkElement display、ShowElement 请求内建议、XLink / FullSubList / mapped alias、plain group 展开。
- Assembly display 与 Joint 输入元数据。
- C2-M1 统一 MapperHistory core：`NamedShape` 新增 `mapper_history` JSON，现有 `ElementHistory`、preserved alias、terminal split / deleted、merge、Link retag、transformed copy 和 Sketch InternalShape summary 子集已通过统一 event schema 序列化或转换。
- C2-M2 FaceMaker / WireJoiner history producer：FaceMaker 输出 edge / bounded face producer evidence，WireJoiner open export 输出 producer identity 与 target shape；`topo/named_shape` 优先消费这些 evidence 生成 `mapper_history`，`internal_element_map` 只保留唯一 alias。
- C2-M3 Reference resolver + ExternalGeometry 状态机基础：`document` 解析 ExternalGeometry flags；SketchObject 支持 Defining / Frozen / Detached / Missing / Sync 的请求内语义；ReferenceShadow fingerprint / BREP 恢复仍集中在 `topo/reference_matcher` 和 `runtime/recompute`，成功时输出 `elementReferenceUpdates` / `documentObjectUpdates`。
- C2-M4 Sketch InternalShape 主路径切换：复杂 split/deleted/open-export 命名只从 FaceMaker / WireJoiner producer evidence 进入 `mapper_history` 和 terminal history；summary-only history 仅作为 `summary_only:*` diagnostic；`internal_element_map` 不再承担复杂 split / deleted 判断。
- C2-M5 taper ThruSections 子路径：Pad / Pocket / Part::Extrusion 当前 Length、Two sides、Symmetric 和 inner-wire taper fixture 通过 `BRepOffsetAPI_ThruSections` maker / section source history 写入统一 `mapper_history`，不再发布 `known_gap:taper_history`。
- C2-M5 DressUp SupportTransform AddSubShape slot 子路径：Mirrored / chained Fillet-Chamfer fixture 消费 DressUp add/sub slot 的 `NamedShape`，继续传播 source-prefixed alias、maker history、terminal split / deleted 和 merge。
- C2-M5 RefineModel 当前 P7 覆盖子路径：Pad、Pocket、Hole、DressUp 和 Transformed refined support fixture 消费 RefineModel generated / modified / terminal deleted / merge history，统一进入 `mapper_history`。
- C2-M6 transformed / pattern Add/Sub ownership 子路径：LinearPattern、PolarPattern、Scaled、MultiTransform 的代表 fixture 保留 transformed copy alias、source object history、multi-original replay、refined prefix support 和 terminal split / deleted / merge；capabilities 暴露 `transformed_pattern_addsub_ownership`。
- C2-M7a Link transaction 当前覆盖子路径：`documentObjectUpdates` 表达 ShowElement create / claim / sync / delete / toggle-off、ElementCount owner list sync、ElementList owner / child sync 和 CopyOnChangeOwned child sync；capabilities 暴露 `link_transaction`，完整 `_ChildCache` 与 copy-on-change deep copy 生命周期仍是 gap。
- C2-M7b Link reference lifecycle 当前覆盖子路径：`PropertyXLink*`、`FullSubList`、external tag mapped postfix、source-prefixed stable key、多层 object / label LinkSub 和 `PropertyXLinkList` subset compound 进入 P8 回归；capabilities 暴露 `link_reference_lifecycle`，document hash 与 rename recovery 仍是 gap。
- C2-M7c Assembly solver adapter 子路径：AssemblyObject 输出 `skipped_no_joints` / `solved_noop` / `unsupported`，GroundedJoint-only fixture 走 no-op success，未迁移 `JointType` 输出 `unsupported_assembly_solver` diagnostics；capabilities 暴露 solver adapter 状态和完整 Ondsel solver gap。
- C2-M7d adapter contract 当前覆盖子路径：C ABI recompute / capabilities / export buffer、CLI recompute / file export 共用 `cad-core-lib`，C API export 拒绝 server file path 并返回 metadata diagnostics；capabilities 暴露 `adapters`。
- C2-M8 验收冻结当前状态：阶段收口 unittest 组合 324 tests OK，`tests.test_expected_fixtures` OK、skipped=9；remaining gaps 均通过 capabilities / diagnostics / expected policy 显式暴露。

当前未完成的深层边界：

- 完整 FreeCAD native `ExternalGeometryExtension` 生命周期冻结，包括旧 `ExternalGeo` 几何持久复用、复杂 Missing 修复 UI 流程和跨文档 postfix 场景。
- 跨 PartDesign / Part / Link 的完整 MapperHistory producer / ElementMap 生命周期。
- ShapeFix 主路径 history、RefineModel 更复杂 identity-change case、transformed history 收敛、DressUp 非 SupportTransform 复杂参数余量，以及 taper 超出当前 ThruSections 覆盖子集的复杂 source ownership；其中 ShapeFix 主路径缺口已通过 `topo_history.remaining_gaps.shapefix_history` 暴露。
- PartDesign transformed / pattern 超出当前 Add/Sub ownership 子路径的完整 history。
- 完整 FreeCAD Link `_ChildCache` / copy-on-change deep copy 生命周期、cross-document 文档哈希和 source / label rename 恢复。
- 完整 Ondsel Assembly solver、solver 输出 placement update、完整 Joint placement / constraint。
- Worker / WASM / Web adapter、streaming mesh limits、binary mesh protocol 产品化。

## 2.0 分阶段路线

| 阶段 | 主线 | 目标 |
| --- | --- | --- |
| C2-M0 | 基线锁定 | 固定当前测试、known gap、capabilities 和未提交变更边界 |
| C2-M1 | MapperHistory core | 在 `topo` 建立统一 history event / ElementMap 生命周期 |
| C2-M2 | FaceMaker / WireJoiner history | 让 `geometry` 产出可被 `topo` 消费的 history evidence |
| C2-M3 | Reference resolver + ExternalGeometry | 在 `runtime` 统一旧引用恢复，在 Sketcher 表达 ExternalGeometry 状态机 |
| C2-M4 | Sketch InternalShape 主路径切换 | InternalFace / InternalEdge / InternalVertex 经 MapperHistory 命名，删除临时 fallback |
| C2-M5 | History 收敛 | ShapeFix / Refine / taper / transformed / DressUp 接入统一 MapperHistory |
| C2-M6 | PartDesign 复杂 ownership | transformed / pattern / DressUp 链路的复杂 source ownership 与 terminal history |
| C2-M7 | P8 产品化 | Link 账本、ShowElement 写回生命周期、Assembly solver、Worker / WASM / Web adapter |
| C2-M8 | 验收冻结 | oracle、fixture、capabilities、接口文档和回归门禁冻结；当前为显式 gap 冻结状态 |

## 推荐推进顺序

1. 先做 C2-M0 到 C2-M4。它们决定稳定 subname、ExternalGeometry 和 InternalShape 是否有统一主路径。
2. 再做 C2-M5 到 C2-M6。它们把 PartDesign 生态从“基础子集可用”推进到“复杂链路引用可恢复”。
3. 最后做 C2-M7 到 C2-M8。Link / Assembly / Web adapter 依赖前面的 topo naming 和 reference resolver，否则容易变成前端或 adapter 侧补丁。

## 非目标

- 不实现完整 FreeCAD GUI / ViewProvider / Workbench。
- 不把 BREP 作为前端或后端长期状态；唯一例外仍是 `ReferenceShadow.brep` 的旧单 subshape snapshot。
- 不在 adapter、document parser 或 sketch executor 中按 fixture 名称、几何类型排序、source edge 猜测来修正输出。
- 不把 Assembly solver 作为 P5/P6 topo naming 主线的前置条件。
