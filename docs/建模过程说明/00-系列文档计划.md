# FreeCAD 建模过程说明系列文档计划

本文是计划和大纲，不是系列正文。后续系列文档的目标，是用大白话和图文把 FreeCAD 里一次完整 CAD 建模过程讲清楚：从新建文档、画草图、生成实体、编辑特征，到把多个零件放进装配体并用关节求解。

## 1. 写作目标

- 让读者先知道“点了哪个按钮、创建了哪个对象、对象里存了什么属性、重算时谁先执行、最后形状怎么出来”。
- 每篇都用“用户看到的动作”带出“源码里发生的事”，避免只写源码流水账。
- 每个关键步骤都配图：操作界面截图、对象关系图、几何变化图、重算依赖图。图先用 Mermaid/简图表达结构，必要时再补真实截图。
- 系列主线只覆盖建模链路：草图、实体建模、特征编辑、装配体。TechDraw、CAM、FEM、BIM、渲染等作为后续扩展，不放进第一版主线。

## 2. 当前项目阅读结论

FreeCAD 的建模链路可以按这几层理解：

- `src/App/` 是底座：`Document` 管文档对象，`DocumentObject` 管属性、依赖和重算，`Property*` 管对象之间的引用，`GeoFeature` 管三维放置。
- `src/Mod/Sketcher/` 负责二维草图：`SketchObject` 保存几何、约束、外部几何和求解结果，GUI 命令负责画线、画圆、加尺寸约束。
- `src/Mod/Part/` 负责拓扑形状：`Part::Feature` 以 `Shape` 作为输出，`TopoShape` 封装 OCCT 的边、线框、面、壳、实体、布尔和 refine。
- `src/Mod/PartDesign/` 负责参数化实体：`Body` 组织特征链，`FeatureSketchBased` 把草图轮廓变成可拉伸/旋转的面，`Pad/Pocket/Revolution/Loft/Pipe/Hole/DressUp/Pattern` 等特征一步步改造实体。
- `src/Mod/Assembly/` 负责装配：`AssemblyObject` 管组件、关节和求解，`AssemblyLink` 表示装配中的引用件，`JointGroup` 管关节集合，GUI 负责选择组件、创建关节、显示求解问题。
- `data/examples/`、`data/tests/`、`src/Mod/*/*Tests/` 可作为后续截图、最小模型和行为校验来源。

主线图如下：

```mermaid
flowchart LR
    A[新建 Document] --> B[创建 Body]
    B --> C[创建 Sketch]
    C --> D[画二维几何和约束]
    D --> E[Sketch 求解并输出轮廓 Shape]
    E --> F[PartDesign 特征: Pad / Pocket / Revolve]
    F --> G[Body 更新 Tip 实体]
    G --> H[多个零件通过 Link 放入 Assembly]
    H --> I[创建 Joint]
    I --> J[Assembly 求解并更新 Placement]
```

## 4. 每篇固定写法

每篇文档都按同一套结构写，读者不用重新适应：

1. 一句话结论：这一步在建模链路里负责什么。
2. 用户视角：用户在界面里点什么、选什么、看到什么变化。
3. 对象视角：新建或修改了哪些 `DocumentObject`，关键属性是什么。
4. 几何视角：线、面、实体或装配位置如何变化。
5. 重算视角：谁被 touch，谁执行 `mustExecute()` / `execute()`，输出写到哪里。
6. 源码索引：列出本篇最该看的文件和函数，不展开无关模块。
7. 图示清单：本篇应该画哪些图，截图从哪个示例或测试生成。
8. 常见误区：用大白话解释容易误解的概念，例如“Body 不是最终形状本身，Tip 指向当前最终特征”。

## 6. 示例模型计划

后续正文建议只围绕一个贯穿案例展开，避免每篇换例子：

- 零件 A：一个带安装孔和圆角的支架。覆盖草图、约束、Pad、Pocket、Hole、Fillet、LinearPattern。
- 零件 B：一根带轴孔或销孔的连接件。覆盖 Revolve 或 Pocket，以及与零件 A 的装配引用。
- 装配体：把零件 A、零件 B 和一个简单销轴放进 Assembly。覆盖 Link、固定件、转动关节、距离关节、求解结果。

## 8. 验收标准

后续系列正文完成时，应满足这些标准：

- 能从 `00` 顺着读到 `16`，不跳源码也能理解 FreeCAD 一次完整建模过程。
- 每篇至少有一张流程图或结构图，涉及界面操作的篇章至少有一张截图或截图计划。
- 每篇都能回答四个问题：用户做了什么、FreeCAD 创建/修改了什么对象、几何结果怎么变化、重算如何触发。
- 所有源码索引都指向当前仓库存在的文件。
- 第一版不写 CAM/FEM/BIM/TechDraw 正文，只在总览里说明它们是建模后的扩展方向。
