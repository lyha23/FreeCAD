## WireJoiner 当前不可回退边界

- 不恢复 `openExportOverride`、`purgeAsOriginalOpenEdge`、公开 noOriginal candidate 字段、公开 source-edge producer output/count、result-slot output-shape diagnostics、endpoint-materialization 公开诊断或 EdgeInfo open-wire 重导出 fallback。
- 不在 `topo_shape.cpp`、adapter 或 expected JSON 中按 source index、几何形态、输出顺序、fixture 名称重新推断 open-export relation。
- `Sketch.InternalShape.mapper_history` 的 WireJoiner open-export 只能消费 concrete `wire_joiner:open_export` event、child-wire ownership 和 ElementMap / terminal history evidence；producer identity 只保留为 audit，不作为 mapper event 解释层。
- one-to-one alias 才能进入 `ElementMap`；split / deleted / ambiguous 关系保留在 `MapperHistory`、terminal history 或 diagnostics 中，不伪造成唯一 alias。

## 下一阶段任务

WireJoiner full ledger 已完成本轮收口；下一阶段不再以 WireJoiner bridge deletion 作为 C3 blocker。Part Workbench surface family 继续从具体 feature-family 推进：Loft、Sweep 和 Filling helper 已有 expected-backed 第一批，后续只从 `Linearize=true`、face / vertex profile expected、Filling support/order/constraint/param family、GeomPlate 等明确边界进入，不恢复“完整 surface family”宽泛 gap。

后续若继续推进 C3，只从仍非 `covered_full` 项进入：Assembly representative fallback 只能作为 fallback DTO 维护；Pad / Pocket `UpToShape` 多面 LinkSubList 已作为 PartDesign 当前基线维护，不复用 WireJoiner 或 taper history 名称。
