## 下一阶段候选任务

1. WireJoiner full ledger：只沿 FreeCAD `WireJoinerP::EdgeInfo / WireInfo / myShapesToReturn / MapperHistory / ElementMap` 路径推进，不用输出 pruning、fixture 特判或几何猜测当主路径。
2. UpToShape multi-face：若要从 diagnostic-only 进入实现，先拆 Pad / Pocket UpToShape 多面选择的 FreeCAD 源码依据、fixture 和 diagnostics，不复用已收口的 taper history gap 名称。
3. 后续新增缺口必须拆成具体 producer、lifecycle、feature-family、JointType 或 adapter contract 项；不得恢复旧 local-history gap 清单、旧 taper known-gap topo marker 或 broad `known_gaps`。
