# FreeCAD 语义矩阵

本文件是 C3-M0 的主账本：每个条目都按 FreeCAD 模块、源码依据、`cad-core` 落点、当前状态、优先级、阶段、oracle / fixture 和 capabilities / diagnostics 暴露方式追踪。后续 C3-M1 到 C3-M7 只从本矩阵领取实现项。

## 状态与优先级

- `done`：2.0 已有源码落点、fixture / test 和 capability 暴露，本轮只作为基线引用。
- `partial`：已有代表路径，但 FreeCAD 语义或 history 生命周期没有覆盖完整。
- `diagnostic_only`：当前只暴露 warning / error / known unsupported，不产出完整语义。
- `known_gap`：2.0 已显式暴露，3.0 必须拆成可执行任务。
- `not_started`：尚无正式 `cad-core` 主路径。

优先级沿用 3.0 定义：P0 影响稳定引用、错误 recompute 或长期编辑；P1 影响常用 Sketch / Part / PartDesign 建模链；P2 影响 Link / Assembly / Web 产品化；P3 为低频或非冻结阻塞项。
