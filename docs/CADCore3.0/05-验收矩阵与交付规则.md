# 验收矩阵与交付规则

本文件定义 CAD Core 3.0 的完成标准。3.0 不以“feature 数量”验收，而以 FreeCAD 语义是否可追溯、可重建、可诊断、可回归验收。

## 总体验收门槛

每个 3.0 任务必须满足：

- 写明 FreeCAD 源码依据：绝对路径、类 / 函数、关键字段或短句。
- 写明 cad-core 落点：`app`、`base`、`graph`、`runtime`、`sketcher`、`part`、`part_design`、`mesh`、`assembly`、`adapters`。
- 有成功 fixture / oracle，或者明确 diagnostics / `known_gap`。
- 不从 fixture 输出倒推业务逻辑。
- 不在 adapter、runtime 输出层、sketch executor 或前端中做 fixture 特判。
- 修改 C++ 后执行相关 build / test；文档修改至少执行 `git diff --check`。

## 阶段验收矩阵

| 阶段 | 必须覆盖 | 通过标准 |
| --- | --- | --- |
| C3-M0 | FreeCAD 语义矩阵、capabilities 对照、oracle 队列 | P0 / P1 gap 均有源码依据、cad-core 落点和阶段归属 |
| C3-M1 | full MapperHistory、ShapeFix、import shape ElementMap | ShapeFix / import / transformed / Link retag 后 history 可追溯 |
| C3-M2 | ExternalGeometry native 生命周期、document hash、rename recovery | Frozen / Detached / Missing / Sync 成功和失败路径均可验收 |
| C3-M3 | Sketcher solver、ExternalGeometry projection / intersection、InternalShape oracle | solver state、diagnostics、stable subname 同步验收 |
| C3-M4 | Part primitives / operations / import-export / ShapeFix diagnostics | Part feature 输出 shape + NamedShape + history 或明确 diagnostics |
| C3-M5 | PartDesign full family、pattern full history、DressUp / Hole 参数余量 | 常用 Body workflow 长期编辑后可稳定重算 |
| C3-M6 | Link `_ChildCache`、copy-on-change、document hash、Assembly solver | Link 写回可被前端持久应用，Assembly placement 可写回 |
| C3-M7 | Worker / WASM / streaming mesh / binary protocol | 多 adapter 核心结果一致，adapter 不承载业务语义 |
| C3-M8 | 3.0 freeze | oracle、fixtures、capabilities、docs、测试命令全部同步 |

## 重点 fixture / oracle 队列

C3-M0 的可执行队列落在 `oracle-fixture队列.md`，本节只保留阶段级分类。

### TopoNaming / ExternalGeometry

- ShapeFix 修改 / 删除 / 生成 edge、wire、face。
- import STEP / BREP 后的 face / edge / vertex 选择和重算。
- transformed / pattern / DressUp / Link retag 后的 source ownership。
- Frozen / Detached 旧 `ExternalGeo` 几何复用。
- Missing external target 修复、deleted target、document hash mismatch。
- source object rename、label rename、cross-document postfix。

### Sketcher

- 复杂约束状态：冗余、冲突、欠约束、退化。
- full-rank request-local DoF、dependent parameter group、blocked dependent group。
- Symmetric + coupled curve relation geometry update。
- ExternalGeometry projection / intersection：face、edge、vertex、datum、linked target。
- self-intersection + inter-edge intersection + open wire 混合。
- source edge 一对多 fragment、source edge one-to-zero deleted。

### Part

- primitives 全覆盖。
- Boolean / Section / General Fuse / Refine / ShapeFix。
- Extrude / Revolve / Sweep / Loft / Offset / Thickness。
- import/export format、unsupported format、invalid shape diagnostics。

### PartDesign

- Pad / Pocket / FeatureExtrude 参数余量。
- Revolution / Groove / Loft / Pipe / Boolean。
- Hole thread table、head cut、ModelThread。
- Fillet / Chamfer / Draft / Thickness 复杂选择和失败诊断。
- Mirrored / LinearPattern / PolarPattern / Scaled / MultiTransform full history。

### Link / Assembly / Runtime

- `_ChildCache` nested group、orphan reclaim、ShowElement toggle。
- copy-on-change deep copy、owned child mutation、touched tracking。
- FullSubList、XLink、mapped postfix、多层 LinkSub。
- Assembly Fixed / Revolute / Slider / Ball / Distance / Angle grounded real Ondsel fixture、invalid grounded placement validation fixture，以及 Fixed / Revolute / Slider / Ball / Distance / Angle representative fallback DTO。
- solver placement write-back。
- Worker / WASM / binary mesh / streaming mesh limits。

## 3.0 完成判定

CAD Core 3.0 可以冻结时，应同时满足：

- FreeCAD 语义矩阵中 P0 / P1 项均已实现、明确 diagnostic-only，或保留可解释 known gap。
- capabilities 不再保留 2.0 的笼统 remaining gap；未完成项被拆成可执行、可验证的细项。
- `NamedShape`、ElementMap、MapperHistory、ReferenceShadow、ExternalGeometry、Link retag、Assembly placement update 的引用恢复模型一致。
- Sketcher / Part / PartDesign 常用 workflow 可以长期编辑后稳定 recompute。
- Link transaction 和 Assembly placement update 可以由前端应用回 `DocumentObject graph`。
- CLI / C ABI / Worker / WASM / Web adapter 复用同一 core recompute，不承载额外业务语义。
- expected fixture 若几何可验收但必须暴露 warning / diagnostic，应在 expected JSON 中写 `diagnostic_codes`；只有不可验收场景才使用 `known_gap` 跳过。
