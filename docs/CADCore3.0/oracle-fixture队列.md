## 当前基线

- C3-M1 到 C3-M7 的 fixture 队列已覆盖当前 capability 表中的大类能力。已完成队列保留在下方表格中，避免后续重复领取。
- C3-M8 后的 WireJoiner full ledger 已收口：`wire_joiner.generated_open_export_bridge` 与 `wire_joiner.purge_as_original_bridge` 均为 `covered_full`，remaining gaps 为空。
- 当前源码以 `WireJoinerMapperHistoryProducerEvidence`、openWireCompound child-wire ledger 和 concrete `wire_joiner:open_export` event 表达 open-export、noOriginal、split、deleted 关系；oracle 继续保护 cross / T / segmented / three-overlap 不出现 source/vmap producer 过度认领。
- WireJoiner 已删除的公开字段和 fallback 不得恢复：`openExportOverride`、`purgeAsOriginalOpenEdge`、公开 noOriginal candidate、公开 source-edge producer output/count、result-slot output diagnostics、endpoint-materialization 公开诊断、EdgeInfo open-wire 重导出 fallback。
- 当前关键保护 fixture：P5 open-cutter / cross / T / segmented cutter 不得丢 InternalEdge 或 split history；three-overlap `InternalVertex` 必须保持 19；branch open-cutter 的唯一 child-wire alias `Edge5 -> InternalEdge10` 必须保持。
- Part Workbench surface family 当前只发布精确 feature-family：`Part::RuledSurface` edge/wire expected-backed slice、`Part::ProjectOnSurface` 当前 expected-backed slice、`Part::Loft` profile / `Linearize=true` expected-backed slice、`Part::Sweep` multi-profile / `Linearize=true` expected-backed slice、`Part::FilledFace` helper expected-backed 第一批和 `Part::GeomPlateSurface` helper expected-backed 第一批；ProjectOnSurface projected edge provenance mapper/history、GUI task panel、未验证高级分支、Loft `complex_profile_family`、Sweep advanced PipeShell contract、Filling support/order/constraint/param family、GeomPlate advanced constraints 和完整 surface family 仍需独立队列。
- 所有 native oracle 仍以本地 FreeCAD `src/` 语义为准，必要时通过 `/Applications/FreeCAD.app/Contents/Resources/bin/freecadcmd` 采集。
