# capabilities gap 对照表

本文件把当前 `cad_core_capabilities_json()` 暴露的能力和真实缺口对齐到 CAD Core 3.0 文档。它只记录当前基线和后续接管边界，不记录字段删除过程。

## Sketcher conic arcs 发布口径

- P5CONIC 已发布 `ArcOfHyperbola` / `Part::GeomArcOfHyperbola` 与 `ArcOfParabola` / `Part::GeomArcOfParabola` 的 Sketcher profile / raw edge、construction 过滤、native `ExternalGeo` 和 projected `ExternalGeometry` TopoDS Edge 支持；证据落在 `cad-core/fixtures/p5`、`cad-core/fixtures/p5/expected`、`cad-core/tests/test_p5_sketch.py` 和 `cad-core/tests/test_diagnostics.py`。
- 当前 `cad_core_capabilities_json()` 的 `sketcher.solver` 仍只表达 solver-facing diagnostics / request-local geometry update；conic arcs 是 `SketchObject` geometry / external geometry 能力发布，不把完整 Sketcher solver 内部辅助几何 / conic 约束写成 supported。
- 保持非目标边界：GUI conic edit、完整 Sketcher solver 内部辅助几何 / 约束、未验证的完整 Part workbench conic surface family 均不属于本次 capability。

- cad-core 落点为 `cad-core/src/part/part_geomplate.cpp`、`cad-core/src/part/topo_shape_expansion.cpp`、`cad-core/tools/collect_freecad_expected.py`、`cad-core/tests/test_p8_features.py`、`cad-core/tests/test_expected_fixtures.py` 和 `cad-core/src/adapters/c_api/c_api.cpp` capability metadata。
- 验收证据为 `cad-core/fixtures/c3m4/part-geomplate-curve-point-default.json`、`part-geomplate-invalid-inputs.json`、`cad-core/fixtures/c4m1/part-geomplate-advanced-constraints.json`、`part-geomplate-advanced-deferred.json`、`cad-core/fixtures/c5m7/part-geomplate-initial-surface-g0.json`、`part-geomplate-g1-curve-on-surface.json`、`part-geomplate-curve2d-on-surface.json`、`part-geomplate-projected-curve2d.json`、`part-geomplate-point2d-on-surface.json`、`part-geomplate-mixed-surface-constraints.json`、`part-geomplate-point-custom-criteria.json`、`part-geomplate-curve-criteria-diagnostic.json`、`part-geomplate-wrapper-boundary.json` 及对应 FreeCAD expected / known_gap / focused tests；capability key 为 `part_workbench.geomplate`。
- `c4m1/part-geomplate-advanced-constraints` 只证明 explicit approximation params 和 3D `curve3d` / `point3d` source evidence expected-backed；`c5m7/part-geomplate-initial-surface-g0` 证明 `InitialSurface` / `Surface` 解析到真实 face source 并调用 `LoadInitSurface` expected-backed；`c5m7/part-geomplate-g1-curve-on-surface` 只证明 cad-core source-backed G1 DTO/executor，FreeCAD expected 仍是 native oracle blocker；`c5m7/part-geomplate-projected-curve2d` 只证明 cad-core source-backed projected 2D DTO/executor，FreeCAD expected 仍是 `setProjectedCurve` native oracle blocker。
- 不支持声明：G1 curve-on-surface native expected oracle、ProjectedCurve2d native expected oracle、curve criteria setter support（当前 FreeCAD wrapper 直接抛 `NotImplementedError`）、`Part.PlateSurface.Curves` persistent wrapper lifecycle、GUI GeomPlate feature、原生 `Part::GeomPlate` DocumentObject、Filling `BRepOffsetAPI_MakeFilling` 扩展、full advanced support 或完整 Part surface family。

## 收口规则

- 不恢复笼统 `complete_mapper_history`、`known_gaps`、旧 taper local-history gap 或旧 helper output gap。
- 不用空 `remaining_gaps` 伪装 full coverage；`covered_representative` 和 diagnostic-only boundary 必须明确写出边界。
- WireJoiner 后续只允许沿 FreeCAD `WireJoinerP::EdgeInfo / WireInfo / myShapesToReturn / MapperHistory / ElementMap` 路径维护，不恢复 producer bridge / candidate / result-slot 公开字段。
- `ElementMap` 只承接唯一 target alias；split / deleted / ambiguous relation 必须保留在 `MapperHistory`、terminal history 或 diagnostics 中。
- 所有新增 capability 必须有 FreeCAD 源码依据、cad-core 落点、fixture / test 或稳定 diagnostic。
