# 【已实现】C51-S6 freeze 收口总结

## 结论

CADCore5.1 PartDesign 剩余 deferred 语义已经完成 freeze：S0-S5 的父 blocker 均在 child rows supported 或 exact blocker 化后关闭，S6 关闭 `C51-BLK-601`，队列应为空。C51 不再保留旧 C5 broad deferred / broad non-goal 口径。

## Supported rows

- Revolution / Groove：Revolution UpToFirst / UpToLast / UpToFace、Profile.SubList/InternalFace、FuseOrder=FeatureFirst、DatumLine/App::Line/Sketch AxisN ReferenceAxis supported；Groove UpTo 保留 exact native BRepFeat blocker。
- Boolean：Compound product Body replacement、Section standalone edge/wire、Section Body Tip `partdesign_body_tip_non_solid`、no-intersection `no_intersection` diagnostics supported。
- Loft：Closed/multi-section、multi-wire ordering、explicit subelement ledger、MapperThruSections / MapperSewing ElementMap propagation supported。
- Pipe：Fixed/Auxiliary/Binormal、Round corner、selected spine / multisection path、front/back MapperSewing supported；source-commented scaling laws and tangent expansion remain exact blockers。
- Datum Attachment：selected non-GUI MapModes、AttachmentOffset、MapReversed/Reverse、MapPathParameter/Parameter、input-driven AttachmentSupport writeback supported；remaining AttachEngine modes remain exact blockers.

- CLI / C ABI / Worker / WASM adapters remain protocol bridges and do not own PartDesign geometry or topology semantics.
