### FreeCAD 依据

- Revolution / Groove：`FeatureRevolved.cpp::tryExecuteRevolved()` 分派 `getUpToFace()` / `getUpToFaceFromLinkSub()` 与 `generateRevolution()`；`FeatureRevolution.cpp::makeShape()` 以 `FuseOrder=FeatureFirst` 切换 `revolve.makeElementFuse(base)`；`FeatureSketchBased.cpp::getAxis()` 支持 `PartDesign::Line`、`App::Line`、Sketch `AxisN` 与 Part edge。
- Boolean：`FeatureBoolean.cpp::execute()` 源码中 `Compound` / `Section` 分支仍被注释禁用，但 `TopoShapeExpansion.cpp::makeElementBoolean()` 已有 `Compound` 与 `Section` maker path；C51-S2 必须写清这是产品化 contract，不得伪称 GUI/native PartDesign Type 已直接支持。
- Loft / Pipe：`FeatureLoft.cpp::getSectionShape()/execute()` 与 `FeaturePipe.cpp::buildPipePath()/setupAlgorithm()/execute()` 分别承担 profile/section ledger、PipeShell setup 和 front/back sewing；`MapperThruSections` / `MapperSewing` 是 ElementMap 正式 owner。
- Datum Attachment：`AttachExtension.cpp::positionBySupport()` 在 `subChanged` 时写回 `AttachmentSupport.setValues()`；`Attacher.cpp::calculateAttachedPlacement()` 使用 `shadowSubs` 与 placement 等价判断恢复 subname；`PropertyLinks.cpp::updateElementReferences()` / `_updateElementReference()` / `PropertyLinkSubList::setValues()` 是下游引用更新依据。
