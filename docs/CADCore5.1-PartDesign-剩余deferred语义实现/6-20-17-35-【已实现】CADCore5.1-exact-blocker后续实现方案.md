# CADCore5.1 exact blocker 后续实现方案

## 当前基线

C51 已完成 freeze：Revolution UpTo、Profile.SubList/InternalFace、FuseOrder、DatumLine/App::Line/Sketch AxisN、PartDesign Loft closed/multi-wire/sewing、PartDesign Pipe Fixed/Auxiliary/Binormal/Round/selected spine/multisection/sewing、Datum selected MapModes 与 request-local writeback 均已 supported。剩余内容不能再按“基础不支持”处理。

## 目标

把 C51 freeze 后留下的 exact blockers 转成可执行的后续路线：先复核 native / source 证据，再决定保持 exact blocker、实现 FreeCAD parity，或明确作为 CAD Core product extension 实现。

## 范围

| 包 | 当前 blocker | 默认动作 | 可进入实现的条件 |
| --- | --- | --- | --- |
| C51X-S1 Groove UpTo | `partdesign_groove_upto_brepfeat_cut_native_failure` | 保持 exact blocker | 新 FreeCAD native oracle 证明同一输入可成功，或产品决定接受 CAD Core divergence |
| C51X-S2 Pipe transformation law | `partdesign_pipe_transformation_laws_source_commented` | 保持 exact blocker | 产品明确需要 CAD Core extension，并定义 request DTO / ScalingData law contract |
| C51X-S2 Pipe tangent expansion | `partdesign_pipe_spine_tangent_source_commented` | 保持 exact blocker | 产品明确需要 CAD Core extension，并补连续边扩张账本 |
| C51X-S3 Datum remaining modes | `datum_attach_engine_remaining_modes` | 分包推进 | 每个 mode family 有 FreeCAD source 调用链、native expected 和 request-local input contract |

## 非目标

- 不在本包实现 `Part::Loft complex_profile_family`、`Part::Sweep` advanced wrapper、Filling / GeomPlate advanced surface family；这些属于 Part Workbench surface family。
- 不恢复 C5 broad deferred / broad non-goal 文案。
- 不把 FreeCAD native 失败的 Groove UpTo 伪装成 parity support。
- 不在 C ABI / CLI / Worker / WASM adapter 写几何或 topo 业务逻辑。
- 不用 bbox、输出顺序、fixture 名称或 adapter 输出修剪替代 `TopoShape` / `MapperHistory` / AttachEngine 语义。

## 最小完整语义批次

### C51X-S1 Groove UpTo

复核 `partdesign-groove-uptofirst-body` 和 `partdesign-groove-uptoface-body` 的 native FreeCAD 失败是否仍成立。若仍失败，只更新 capability/docs 的 exact blocker 证据，不改 cad-core 主路径。若 native 成功，必须实现完整 BRepFeat cut path、Body subtractive replay、ElementMap/history 和 focused tests。

### C51X-S2 Pipe product extension

不能只做一个 `Transformation=Linear` fixture。若进入产品扩展，应同时定义 `Transformation=Linear/S-shape/Interpolation` 的 law DTO、`SpineTangent/AuxiliarySpineTangent` 连续边扩张账本、PipeShell setupAlgorithm 参数、front/back sewing history 和 capability product-contract 文案。

### C51X-S3 Datum AttachEngine

按 mode family 分批：curve frame family、two-point/intersection/proximity line family、three-point/folding plane family、curve normal/binormal/tangent family、focus/edge/center/vertex point family。每批必须有 native expected、input contract、request-local writeback 和 focused tests。

## 实施结果

- C51X-S0 已冻结 live 基线：后续包只承接 C51 freeze exact blockers，`Part::Loft complex_profile_family` 与 `Part::Sweep` advanced wrapper 继续路由到 Part Workbench surface family。
- C51X-S1 已用当前 FreeCADCmd 复核 Groove UpTo：FreeCAD 1.2.0 revision 20260519 对 `partdesign-groove-uptofirst-body` 和 `partdesign-groove-uptoface-body` 仍报 `Groove: Revolution: Up to face: Could not revolve the sketch!`，因此保持 `partdesign_groove_upto_brepfeat_cut_native_failure` exact blocker，不改 cad-core BRepFeat cut 主路径。
- C51X-S2 已复核 Pipe law / tangent：`Transformation=Linear/S-shape/Interpolation` 与 `SpineTangent/AuxiliarySpineTangent` 仍按 `cad-core/fixtures/c51m4/partdesign-pipe-source-backed-blockers.json` 返回 source-backed `unsupported_property`，没有产品 DTO / continuous-edge ledger 前不实现为 FreeCAD parity。
- C51X-S3 已实现 DatumPoint 单输入子批次：`Vertex`、`OnEdge`、`CenterOfMass` 进入 supported，落点为 `cad-core/src/part_design/datum_attachment.h`，新增 `cad-core/fixtures/c51m5/partdesign-datum-point-single-input-modes.json` 与 checked-in FreeCAD expected。
- C51X-S3 后续已实现 DatumLine line-family 子批次：`TwoPointLine`、`IntersectionLine`、`ProximityLine` 进入 supported，落点仍为 `cad-core/src/part_design/datum_attachment.h`，新增 `cad-core/fixtures/c51m5/partdesign-datum-line-family-modes.json`、diagnostic fixture 与 checked-in FreeCAD expected。
- C5-M14 已实现 DatumPoint `ProximityPoint1/2` 子批次：edge-face first-hit、distance fallback、no-hit fallback、dual support request-local writeback 和 diagnostics 进入 supported，新增 `cad-core/fixtures/c51m5/partdesign-datum-point-proximity-modes.json`、diagnostic fixture 与 checked-in FreeCAD expected。`IntersectionPoint`、Focus、curve frame、three-point/folding 等剩余 modes 继续作为分包 exact blockers。
- C51X-S4/C5-M14 已同步 capability / tests / docs：`part_design.datum_attachment` capability 保持 selected AttachEngine supported 口径，并把已支持的 DatumPoint、DatumPoint proximity 与 DatumLine line-family modes 从 `datum_attach_engine_remaining_modes` 移出。

- 每个 exact blocker 被明确归类为 `still_exact_blocker`、`freecad_parity_implemented` 或 `cad_core_product_extension`。
