## 顺序

1. C51X-S0：live baseline、capability、fixtures 和 exact blocker 证据复核。
2. C51X-S1：Groove UpTo native BRepFeat failure 复核；默认保持 exact blocker，除非 FreeCAD native oracle 证明可支持。
3. C51X-S2：Pipe `Transformation=Linear/S-shape/Interpolation` 与 `SpineTangent` / `AuxiliarySpineTangent` 产品扩展裁决。
4. C51X-S3：Datum AttachEngine remaining modes 分包，不把全部 mode 打成一个实现包。
5. C51X-S4：capability、docs、fixtures、tests 和 freeze 收口。

## 边界

- `Part::Loft complex_profile_family` 与 `Part::Sweep` advanced PipeShell wrapper 属于 Part Workbench surface family，不在本 C51 PartDesign 包内实现。
- `partdesign_groove_upto_brepfeat_cut_native_failure` 默认不是 cad-core bug；除非重新采集的 FreeCAD native expected 发生变化，否则只复核并保持 exact blocker。
- Pipe transformation laws / tangent expansion 当前由 FreeCAD 源码注释支撑，若要实现，必须声明为 CAD Core 产品扩展，不能写成 FreeCAD parity。
- Datum AttachEngine remaining modes 必须按同一输入证据、同一 AttachEngine 子类和同一输出 placement/writeback contract 分批，不允许一轮覆盖全部 mode。
