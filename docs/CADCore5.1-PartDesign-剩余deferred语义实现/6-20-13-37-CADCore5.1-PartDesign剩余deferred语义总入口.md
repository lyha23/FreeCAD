## 总体顺序

1. C51-S0：范围重开、FreeCAD 调用链和 oracle 基线。已关闭 `C51-BLK-000`，并将 S1-S5 拆成 child blockers。
2. C51-S1：Revolution / Groove 的 UpTo、Profile subshape、FuseOrder、Datum/App line axis。已关闭 broad deferred；Groove UpTo 留 exact native BRepFeat blocker。
3. C51-S2：Boolean Compound / Section 从 C5-NG-005 转为实现目标。已关闭；Compound supported，Section standalone supported，Section Body Tip / no intersection 为 exact diagnostics。
4. C51-S3：Loft Closed / multi-wire / full MapperSewing。已关闭；C5 known-gap expected 已转 active parity，`c51m3` 镜像覆盖 Closed/multi-wire/AllowCompound，MapperSewing 由 topo history 传播。
5. C51-S4：Pipe Auxiliary / Binormal / Fixed / Round / scaling / SpineTangent / full sewing。已关闭；Fixed/Auxiliary/Binormal、Round、selected spine / multisection path 和 front/back MapperSewing supported，scaling laws 与 tangent expansion 是 exact source blockers。
6. C51-S5：Datum AttachEngine selected map modes 和 input-driven AttachmentSupport shadow-sub writeback。已关闭；首批 selected modes、offset/reverse/path parameter 与 request-local writeback supported，剩余未覆盖 map modes 为 exact blocker。
7. C51-S6：freeze 收口。已关闭；docs、capability、fixtures、tests 和 remaining boundary 已同步。

## Freeze 边界

- Supported rows：`C51-BLK-112`、`113`、`114`、`211`、`212`、`213`、`311`、`312`、`313`、`412`、`414`、`511`、`512`、`513`、`514` 已关闭为 supported；`C51-BLK-111`、`411`、`413`、`501` 已关闭为 supported-with-exact-blocker。
- Remaining exact blockers：`partdesign_groove_upto_brepfeat_cut_native_failure`、`partdesign_pipe_transformation_laws_source_commented`、`partdesign_pipe_spine_tangent_source_commented`、`datum_attach_engine_remaining_modes`。
- Attachment non-goal 只限 GUI Attachment editor / ViewProvider / TaskPanel / visual resize；跨请求后端 attachment session 仍是全局 non-goal。
- S6 后队列应为空；后续只能围绕上面的 exact blockers 新开 bounded follow-up，不得恢复旧 C5 broad deferred 文案。

## S0 基线结果

- 唯一继续 non-goal 的 Attachment 项是 GUI editor / ViewProvider / TaskPanel / visual resize。`C51-NG-002` 不能阻挡非 GUI AttachEngine 和 AttachmentSupport writeback。
- Boolean `Compound` / `Section` 不再沿用 `C5-NG-005`。PartDesign 源码中这两个 Type 的分支被注释禁用；C51-S2 已把产品化来源限定为 Part `TopoShape::makeElementBoolean(Compound/Section)` 与 CAD Core request contract：Compound 可作为 Body replacement，Section 只作为 standalone edge/wire result，进入 Body Tip 返回 `partdesign_body_tip_non_solid`。
- AttachmentSupport writeback 只能基于 request input 的 `StableSubList`、`ShadowSub`、`ReferenceShadow`、旧 subname 和当前 graph 生成 `documentObjectUpdates` / `elementReferenceUpdates` 建议，不允许后端 session。
