# C7-M3 S4 实现或 no-code 发布收口

## 目标

按 S3 gate 执行实现或 no-code publication closure。若 S3 没有 `backend_gap_requires_implementation`，S4 不改 C++，只同步 docs/matrix/capability 发布口径。

## 必读

- S3 完成后的本包 README、总入口、方案和 `矩阵/*.tsv`
- S3 明确列出的 FreeCAD 源码和 cad-core 修改目标
- `AGENTS.md` 中 FreeCAD 迁移实现纪律、OpenCascade 使用规则和测试指南

## 动作

1. 记录 live baseline 和队列状态。
2. 读取 S3 gate。没有 backend gap 时走 no-code closure。
3. 若 S3 授权实现，先写清 FreeCAD 调用链到 cad-core 分层映射，再修改代码。
4. 涉及引用恢复时，优先补正式 `topo` / history / naming 能力，不允许 adapter/output 层猜测。
5. 按实际修改范围补 focused tests、fixtures、expected 或 capability docs。
6. 把本文件文件名和一级标题标记为 `【已实现】`，队列推进到 S5。

## 非目标

- 不扩大到 S3 未授权 scope。
- 不靠 fixture 名、边顺序、source edge 形态猜测实现。
- 不运行全量 FreeCAD build。
