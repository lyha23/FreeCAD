# P5P6-S1 FreeCAD 源码候选矩阵

## 目标

P5P6-S1 在 S0 冻结范围后，从本地 FreeCAD 源码生成 P5/P6 联合主线候选清单。它只建立候选入口，不做 supported 判断，不采 oracle，不写 C++。

## 源码 authority

以本地源码为准：

- `~/Chili3DProject/FreeCAD/src/App`
- `~/Chili3DProject/FreeCAD/src/Mod/Sketcher/App`
- `~/Chili3DProject/FreeCAD/src/Mod/Part/App`
- `~/Chili3DProject/FreeCAD/src/Mod/PartDesign/App`

不使用网页作为语义 authority。

## S0 冻结的扫描轴

| 扫描轴 | S0 裁决 | S1 处理方式 |
| --- | --- | --- |
| ExternalGeometry 状态机 | 纳入 | 扫描 `SketchObjectExternal.cpp`、`ExternalGeometryExtension.*`、`ExternalGeometryFacade.*` 的 ref、flag、projection/intersection 和 missing repair 路径。 |
| reference resolver | 纳入 | 扫描 `GeoFeature::resolveElement()`、`PropertyLinkBase::_updateElementReference()`、shadow / LinkSub / SubList 更新路径。 |
| ElementMap / MappedName | 纳入 | 扫描 `ElementMap::addName()`、`find()`、`findAll()`、`getElementHistory()`、`traceElement()`、child map 和 postfix 路径。 |
| MapperHistory / TopoShape | 纳入 | 扫描 `MapperMaker`、`MapperHistory`、`makeShapeWithElementMap()`、`PropertyTopoShape` 和 maker history 消费路径。 |
| FaceMaker / WireJoiner | 纳入 | 扫描 `FaceMaker::postBuild()`、`FaceMakerBuildFace`、`WireJoinerP::EdgeInfo`、`WireInfo`、`openWireCompound` 和 `BRepTools_History`。 |
| solver / GUI / Python wrapper | 排除或专项确认 | 记录候选但标路由提示，交给 S2/S3/S4/S5 排除或复审。 |

## 候选 TSV 字段

`p5p6_source_candidates.tsv` 最少字段：

```text
candidate_id	source_file	freecad_symbol	semantic_axis	source_evidence	cad_core_landing	scope_hint	next_step
```

候选 ID 使用 `P5P6-CAND-###`，只代表源码命中和后续路由，不代表实现任务。

## 路由规则

- FreeCAD 源码命中不直接变成 blocker。
- GUI / wrapper / session API 命中不直接删除，先交给 S2 或专项文件写明排除。
- 当前 P5/P6 已覆盖的子集仍要带候选来源，但不自动升级为完整 supported。
- 任何需要实现的项必须先在 S2 变成 `notCollected` 或 `backendGap`。

## 验收

```bash
rg -n "rebuildExternalGeometry|ExternalGeometryExtension|resolveElement|updateElementReference|ElementMap|MappedName|MapperHistory|MapperMaker|postBuild|myPreSplitHistory|mySplitter|EdgeInfo|WireInfo|openWireCompound|getOpenWires" src/App src/Mod/Sketcher/App src/Mod/Part/App
git diff --check
```

实际命令可由脚本替代，但脚本必须保留可复核的候选 TSV。

## 非目标

- 不判定 `supported`。
- 不采 FreeCAD oracle。
- 不写 C++。
- 不从 cad-core 当前输出倒推候选。
