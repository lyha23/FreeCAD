## 状态词典（S0 冻结）

| 状态 | P5P6 含义 |
| --- | --- |
| `supported` | 有 FreeCAD 源码依据、cad-core 实现、checked-in fixture / focused test 或明确源码复核证明 |
| `notCollected` | 属于本主线范围，但缺 FreeCAD expected 或 focused evidence |
| `backendGap` | 已有 FreeCAD 依据和 cad-core 不匹配证据，需要实现 |
| `unsupported` | 本阶段不支持但用户/协议可见，必须有 diagnostic |
| `nonGoal` | 经 S0/S2/S3/S4/S5 明确排除，必须写明重新打开条件 |
| `releaseGate` | 实现已完成但还需删除 fallback、跑回归或回写台账 |
