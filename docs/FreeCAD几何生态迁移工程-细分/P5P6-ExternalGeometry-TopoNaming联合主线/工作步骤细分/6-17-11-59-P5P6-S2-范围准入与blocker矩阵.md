# P5P6-S2 范围准入与 blocker 矩阵

## 目标

P5P6-S2 把 S1 的候选清单转成可执行矩阵。它决定哪些项进入 oracle / 实现队列，哪些公开为 nonGoal，哪些只保留为 unsupported diagnostic。

## 输入

- P5P6-S0 声明口径。
- P5P6-S1 候选 TSV。
- P5 / P6 / P5b / 13 方案文档。
- 当前 `cad-core` 源码和 fixtures。

## 矩阵产物

本轮维护：

- `p5p6_scope_review_matrix.tsv`
- `p5p6_non_goal_registry.tsv`
- `p5p6_blocker_queue.tsv`
- `p5p6_backend_gap_classification.tsv`

`p5p6_scope_review_matrix.tsv` 最少字段：

```text
scope_id	source_candidate	semantic_item	current_status	scope_reason	cad_core_landing	fixture_or_test_route	next_step
```

## 当前 seed 状态

当前矩阵是 seed，不是收口状态：

- `p5p6_scope_review_matrix.tsv`：包含 MapperHistory core、ElementMap lifecycle、FaceMaker producer、WireJoiner producer、runtime resolver、ReferenceShadow、ExternalGeometry Defining / Frozen / Detached / Missing、InternalShape consumer switch 和 fallback deletion 等行。
- `p5p6_blocker_queue.tsv`：包含需要 oracle、实现或 release gate 的初始队列。
- `p5p6_non_goal_registry.tsv`：包含完整 solver、持久 shape cache、GUI/workbench、Assembly solver / full Link transaction、ambiguous split 自动唯一恢复等排除项。
- `p5p6_backend_gap_classification.tsv`：按 topo、part history、runtime resolver、sketcher ExternalGeometry、consumer switch 聚合。

## 分类规则

| 情况 | P5P6 状态 |
| --- | --- |
| 当前 cad-core 已覆盖且有 checked-in fixture / focused test | `supported` |
| 属于范围内但缺 FreeCAD expected 或 focused evidence | `notCollected` |
| 已有 FreeCAD 源码依据和 cad-core 不匹配证据 | `backendGap` |
| 本阶段不支持但用户/协议必须知道 | `unsupported` |
| S0 或专项复审明确排除 | `nonGoal` |
| 实现后还需要 fallback 删除、文档回写或阶段回归 | `releaseGate` |

## blocker 路由

- `notCollected` 进入 S6 oracle 队列。
- `backendGap` 进入 S6 实现队列，但必须已经有 oracle 或 focused failure。
- `unsupported` 进入 S6 diagnostic / capability 队列。
- `nonGoal` 进入公开排除清单，不进入实现队列。
- `releaseGate` 只在实现完成后用于收口，不得作为长期状态。

## nonGoal 要求

每个 `nonGoal` 必须写清：

- FreeCAD 或 cad-core 架构依据。
- 为什么不属于本主线。
- 用户或协议表现。
- 重新打开条件。

不能只写“暂不支持”。

## 非目标

- 不用 fixture 输出倒推分类。
- 不把 S1 扫描遗漏当成 nonGoal。
- 不在 blocker 关闭前写 C++。
- 不把 seed matrix 写成已发布状态。
