## 分类裁决

| 状态 | 本轮使用方式 |
| --- | --- |
| `supported` | 只给当前 cad-core 已有源码实现且有 checked-in fixture / focused test / capability 证据的范围项，例如 MapperHistory event schema、ElementMap child-map、resolver、ReferenceShadow、ExternalGeometry 基础投影和 PartDesign 下游消费者。 |
| `notCollected` | 只用于缺 FreeCAD oracle 的 ExternalGeometry 状态语义：Defining profile、Frozen / Sync / Detached / unresolved Missing 的 source-changed 行为。 |
| `backendGap` | 只用于 FaceMaker concrete history producer 和 WireJoiner current-member vertex multiplicity parity；两者都有 FreeCAD 源码依据和 cad-core 缺口证据。 |
| `unsupported` | 用于 `Profile.StableSubList=InternalFaceN` 这类 request-local stable selector；当前必须走 `unsupported_stable_subname` diagnostic 或 ReferenceShadow evidence route。 |
| `nonGoal` | 用于完整 solver、跨请求 shape cache、Python / GUI session API、Assembly solver / full Link transaction、ambiguous split 自动唯一恢复、完整对象 BREP protocol。 |
| `releaseGate` | 用于 fallback 删除和 fixture-specific rule audit；不代表发布完成。 |

## blocker 路由

- `P5P6-BLOCK-001` / `002`：进入 S3 / S6 oracle 队列，补 FreeCAD expected 后再决定 supported 或 backendGap。
- `P5P6-BLOCK-003` / `004`：进入 S5 / S6 实现队列，分别关闭 FaceMaker concrete producer 和 WireJoiner vertex multiplicity parity。
- `P5P6-BLOCK-005`：进入 S6 diagnostic / capability 队列；除非 S4/S5 明确提升 InternalShape stable selector，否则保持 unsupported。
- `P5P6-BLOCK-006`：进入 S5 / S6 release gate，删除或注释保留的 summary-only、geometry-match、diagnostic-only fallback。
