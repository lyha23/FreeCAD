## 队列消费规则

| 队列状态 | S6 动作 | 关闭后状态 |
| --- | --- | --- |
| `notCollected` | 采 FreeCAD oracle、补 checked-in expected 或 focused semantic test | 转 `supported`、`backendGap`、`unsupported` 或 `nonGoal` |
| `backendGap` | 按 FreeCAD 调用链补 topo / part / runtime / document / sketcher 实现 | 转 `supported` 或 `releaseGate` |
| `unsupported` | 补 diagnostic、capabilities、协议说明 | 保持 `unsupported`，但发布可解释 |
| `releaseGate` | 删除 fallback、跑分层验证、回写 P5/P6/13 文档 | 转 `closed` |

`unsupported` 不是“永远只写说明”。若用户明确要求修复缺口，并且本地 FreeCAD 源码和现有 cad-core 证据已经能定义 request-local 语义，S6 应把该行提升为实现型目标：先补 C++ / focused tests，再按实际结果把状态改成 `supported`、`backendGap`、`unsupported` 或 `nonGoal`。

## 实施顺序

1. 补 topo/app：MapperHistory event model、ElementMap lifecycle、mapped postfix、source key、terminal diagnostics。
2. 补 part：FaceMaker / WireJoiner history producer。
3. 补 runtime：统一 reference resolver、ReferenceShadow evidence、`elementReferenceUpdates`。
4. 补 document/sketcher：ExternalGeometryExtension fields 和 Defining / Frozen / Detached / Missing / Sync 消费。
5. 切换 Sketch InternalShape / ExternalGeometry consumer。
6. 删除旧 fallback，回写矩阵和方案文档。
