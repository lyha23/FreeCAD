# P5P6-S6 Oracle、实现与发布闸门

## 目标

P5P6-S6 只消费 S2-S5 产生的 `notCollected` / `backendGap` / `unsupported` / `releaseGate` 队列。它不重新定义范围，不绕过矩阵，不从 fixture 输出倒推业务逻辑。

## 闸门输入

- S0 已冻结声明口径、状态词典和红线。
- S1 已生成源码候选矩阵。
- S2 已生成 scope review、nonGoal registry、blocker queue 和 backendGap 分类。
- S3 已关闭 ExternalGeometry 状态机边界。
- S4 已关闭 MapperHistory / ElementMap 生命周期和持久状态边界。
- S5 已关闭 FaceMaker / WireJoiner producer 与 fallback 删除边界。

## 队列消费规则

| 队列状态 | S6 动作 | 关闭后状态 |
| --- | --- | --- |
| `notCollected` | 采 FreeCAD oracle、补 checked-in expected 或 focused semantic test | 转 `supported`、`backendGap`、`unsupported` 或 `nonGoal` |
| `backendGap` | 按 FreeCAD 调用链补 topo / part / runtime / document / sketcher 实现 | 转 `supported` 或 `releaseGate` |
| `unsupported` | 补 diagnostic、capabilities、协议说明 | 保持 `unsupported`，但发布可解释 |
| `releaseGate` | 删除 fallback、跑分层验证、回写 P5/P6/13 文档 | 转 `closed` |

## 实施顺序

1. 补 topo/app：MapperHistory event model、ElementMap lifecycle、mapped postfix、source key、terminal diagnostics。
2. 补 part：FaceMaker / WireJoiner history producer。
3. 补 runtime：统一 reference resolver、ReferenceShadow evidence、`elementReferenceUpdates`。
4. 补 document/sketcher：ExternalGeometryExtension fields 和 Defining / Frozen / Detached / Missing / Sync 消费。
5. 切换 Sketch InternalShape / ExternalGeometry consumer。
6. 删除旧 fallback，回写矩阵和方案文档。

## 发布闸门 audit

发布前必须重新读取 live TSV：

| 检查项 | 发布要求 |
| --- | --- |
| `p5p6_scope_review_matrix.tsv` | 无未解释的 `notCollected` / `backendGap` |
| `p5p6_blocker_queue.tsv` | 队列为空或全部 closed |
| `p5p6_non_goal_registry.tsv` | 覆盖所有 `nonGoal`，且写明重新打开条件 |
| `p5p6_backend_gap_classification.tsv` | 无未关闭 P0/P1 backendGap |
| P5/P6/13 文档 | 已回写完成状态、剩余风险和验收命令 |
| fallback audit | 无 unexplained summary-only / geometry-match / fixture-specific fallback |

## 非目标

- 不重新扩大 S0 范围。
- 不复用旧 P5/P6 fixture 通过作为本主线通过证明。
- 不把 `notCollected` 直接变成实现任务。
- 不提交含 build 目录、`__pycache__` 或本地生成物的变更。
