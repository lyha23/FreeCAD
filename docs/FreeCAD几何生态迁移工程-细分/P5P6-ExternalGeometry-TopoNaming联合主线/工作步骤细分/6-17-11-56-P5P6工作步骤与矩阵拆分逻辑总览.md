# P5/P6 ExternalGeometry / TopoNaming 工作步骤总入口

## 目标

本目录用于把 P5 Sketcher 外部几何 / 内部元素与 P6 TopoNaming / 引用恢复合并成一条可执行主线。它不是直接开始写 C++，而是先按 L2 的方式建立“声明口径 -> 源码候选 -> 范围矩阵 -> 专项复审 -> oracle / 实现 -> 发布闸门”的准入链条。

主线入口是 `docs/CADCore方案/细化方案/13-ExternalGeometry-TopoNaming下一阶段主线.md`。本目录只负责把该方案拆成可执行步骤和矩阵，不替代 P5/P6 原方案文档。

当前收口状态：P5P6-S0 已实现，已完成声明口径与 live 基线复核；P5P6-S1 已实现，已把本地 FreeCAD 源码入口扩充为候选矩阵；P5P6-S2 已实现，已把候选压成 scope / nonGoal / blocker / backendGap 矩阵；P5P6-S3 已实现，已裁决 ExternalGeometry 状态机 request-local 边界并保留缺 oracle 的 `P5P6-BLOCK-001/002`；P5P6-S4 已实现，已裁决 MapperHistory / ElementMap / ReferenceShadow request-local 生命周期和持久状态排除边界；P5P6-S5 已实现，已裁决 FaceMaker / WireJoiner producer 主路径和 fallback 删除边界，并把 `P5P6-BLOCK-003/004/006` 细化为 S6 可执行项；P5P6-S6 仍为待执行。当前仍未完成 oracle、producer 实现或发布闸门；不得把整个 P5/P6 主线写成“已实现”。

## 执行顺序

1. P5P6-S0 已完成，只冻结声明口径和红线，不进入实现。
2. P5P6-S1 只做 FreeCAD 源码候选扫描，产出候选矩阵。
3. P5P6-S2 已对候选项做状态分类；`notCollected`、`backendGap`、`unsupported` 和 `releaseGate` 已进入 blocker 队列。
4. P5P6-S3 已关闭 ExternalGeometry 状态机边界：projection/intersection、flags parse/capability 和 source-prefixed Missing recovery 保持 supported；Defining 与 Frozen/Sync/Detached/Missing oracle 仍保持 `notCollected`。
5. P5P6-S4 已关闭 MapperHistory / ElementMap / ReferenceShadow 生命周期边界：`P5P6-SCOPE-001/002/003` 保持 supported，`P5P6-SCOPE-012` 保持 unsupported，`P5P6-SCOPE-013` 保持 releaseGate。
6. P5P6-S5 已关闭 FaceMaker / WireJoiner producer 复审边界：`P5P6-SCOPE-009/010` 保持 backendGap，`P5P6-SCOPE-011/013` 保持 releaseGate，`P5P6-SCOPE-012` 保持 unsupported。
7. P5P6-S6 只消费 S2-S5 留下的队列，按 FreeCAD 调用链补 oracle、实现和验证。
8. 发布前必须清空 blocker queue，回写 P5 / P6 / 13 方案，不复用早期 P5/P6 fixture 通过作为本主线通过证明。

## P5P6 状态纪律

- 除 P5P6-S0 外，新步骤完成前不加 `【已实现】`。
- `notCollected` 只表示缺 FreeCAD expected 或 focused evidence，不能直接写 C++。
- `backendGap` 必须已有 FreeCAD 依据和 cad-core 不匹配证据，不能凭感觉生成。
- `nonGoal` 必须写入 registry，并写清用户/协议表现和重新打开条件。
- 一对多 split、deleted target、Missing object、ambiguous source 都必须输出稳定 diagnostic，不按面积、长度、索引或 geometry type 猜唯一目标。
- 代码实现必须先补 topo / part / runtime 主路径，再切 sketcher consumer；不得在 `sketch_object.cpp` 或 adapter 中继续堆 fixture 特判。
