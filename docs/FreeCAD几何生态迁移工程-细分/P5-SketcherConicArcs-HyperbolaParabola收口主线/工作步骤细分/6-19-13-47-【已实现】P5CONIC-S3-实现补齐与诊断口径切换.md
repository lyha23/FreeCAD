## 操作

1. 若实现已存在，先修正偏差，不重复造第二套结构。
2. 若实现缺失，按 FreeCAD `Restore()` 字段补：
   - Hyperbola：center、normal、majorRadius、minorRadius、angleXU、startAngle、endAngle。
   - Parabola：center、normal、focal、angleXU、startAngle、endAngle。
3. OCCT 构造失败要转成结构化 diagnostics，不能静默丢边。
4. Profile 与 external geometry 都要消费两类 conic arc。
5. 切换测试口径：
   - 支持路径应断言 shape/profile/subshape 或 diagnostics absence。
   - 非法参数路径应断言明确 diagnostic。
   - unsupported 测试不能继续用 FreeCAD supported 的 ArcOfHyperbola 表达。
6. 更新矩阵状态。

## 非目标

- 不迁移完整 conic 内部辅助几何。
- 不把 conic arc 转成 polyline 或 BSpline 来绕过正式类型。
- 不按 fixture 名、几何排序或输出端修剪修正结果。

## S3 实施结论

- `cad-core/src/sketcher/sketch_object_external.cpp::projectExternalCurveEdge()` 已补 `GeomAbs_Hyperbola` 与 `GeomAbs_Parabola` 投影分支，输出正式 `SketchHyperbolaArc` / `SketchParabolaArc` construction external curves，复用现有 conic profile 结构。
- `cad-core/tools/collect_freecad_expected.py::sketch_geometry_value()` 已支持 `ArcOfHyperbola` / `Part::GeomArcOfHyperbola` 与 `ArcOfParabola` / `Part::GeomArcOfParabola`，采集路径使用 `Part.Hyperbola` / `Part.Parabola` 与 `Part.ArcOfHyperbola` / `Part.ArcOfParabola`。
- 新增 P5 fixture/test 覆盖有效 hyperbola、有效 parabola、construction filter、native `ExternalGeo`、projected TopoDS external、invalid params；删除旧 `sketch-unsupported-hyperbola` stale fixture。
- MVP `unsupported-geometry` smoke 已改为真实未支持 kind `OffsetCurve`，valid conic 不再落入 `unsupported_geometry`。
- FreeCAD expected 已采集：`sketch-hyperbola-arc-profile`、`sketch-parabola-arc-profile`、`sketch-conic-arcs-construction-filter`、`sketch-conic-arcs-external-geometry-projected`；采集输出基线为 `FreeCAD 1.2.0devR20260519`。
