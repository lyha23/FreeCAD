# 接口与验收样例

本文只固定 MVP 需要的命令、样例和验收清单。后续 FFI、Web、WASM 都应作为 adapter 接在同一套 CAD Core 之上。

## CLI 命令

MVP 先保留一个主命令：

```bash
cad-core recompute fixtures/mvp/rect-pad.json --output out/rect-pad.result.json
```

如果 mesh 需要单独导出，可以再加：

```bash
cad-core export-mesh fixtures/mvp/rect-pad.json --object Pad --output out/Pad.mesh.json
```

推荐先让 `recompute` 输出 artifact 路径，避免第一版命令过多。

## diagnostics 约定

错误输出必须适合自动测试，不要只放自然语言：

```json
{
  "severity": "error",
  "code": "unsupported_property",
  "object": "Pad",
  "property": "SideType",
  "message": "Only SideType=One side is supported in MVP"
}
```

MVP 需要固定这些 code：

```text
parse_error
duplicate_object_name
duplicate_object_id
missing_property
missing_object
missing_link_target
cycle_dependency
unsupported_type
unsupported_property
unsupported_geometry
open_profile
invalid_length
execution_failed
```

## 最小验收清单

实现完成后逐项检查：

- `empty.json`：命令成功，diagnostics 为空。
- `unknown-type.json`：返回 `unsupported_type`。
- `missing-profile.json`：返回 `missing_property`、`missing_link_target` 或 `missing_object`。
- `open-sketch.json`：返回 `open_profile`，不生成 Pad artifact。
- `rect-pad.json`：返回 Pad mesh、subshape map、bbox，diagnostics 为空。
- `rect-pad` FreeCAD 对照：bbox、体积或 mesh 摘要在允许误差内。

## MVP / P2 之后再扩展

P0 + P1 + P2 稳定后，再按下面顺序继续：

```text
FeatureExtrude ThroughAll
  -> FaceN subshape resolution
  -> UpToFace / UpToShape
  -> Pad / Pocket UpTo fixtures
  -> Two sides / Symmetric / taper
  -> Pattern / Mirror / MultiTransform
  -> Hole / Fillet / Chamfer / Refine
  -> FFI / Web / WASM adapter 产品化
```

不要在 `FeatureExtrude` 的终止语义稳定前先扩 Pattern / Mirror。否则会复制一个不完整的 source feature，后续还要返工。
