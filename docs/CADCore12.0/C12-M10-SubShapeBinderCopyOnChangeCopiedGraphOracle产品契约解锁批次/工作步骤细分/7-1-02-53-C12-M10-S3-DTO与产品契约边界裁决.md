# C12-M10 S3 DTO 与产品契约边界裁决

## 目标

基于 S2 native evidence，裁决哪些 CopyOnChange copied graph 字段允许进入 request-local DTO / product contract，哪些必须 deferred 或 rejected。

## 必读文件

- `../矩阵/c12m10_copy_on_change_dto_contract_fields.tsv`
- `../矩阵/c12m10_copy_on_change_product_contract_gate.tsv`
- `../矩阵/c12m10_copy_on_change_probe_matrix.tsv`
- `../矩阵/c12m10_copy_on_change_non_goal_registry.tsv`
- S2 native artifact 和 S2 step 结果。

## 操作

1. 对 copied object create、property writeback、link rewrite、support sublist rewrite、`BindCopyOnChange`、`PartialLoad`、temporary document、native pointer、BREP / TopoDS、persistent `NamedShape` / `ElementMap` cache、post-request `_tmp_binder` / `_CopiedObjs` state 和 `Cache_*` 逐项裁决。
2. 只允许前端可持久化 DocumentObject graph / `documentObjectUpdates` 字段。
3. 明确 App::Link transport 是 reference vocabulary，不是 SubShapeBinder evidence。
4. 若 S2 未通过 native evidence gate，本步关闭为 `dto_not_reviewed_due_to_native_blocker`。
5. 将本 S3 step 文件重命名为带 `【已实现】` 的同名文件。

## 关闭条件

- `C12M10-DTO-001..012` 均有 allowed / deferred / rejected decision。
- `C12M10-CONTRACT-001..006` 均有 product boundary decision。
- `C12M10-BLOCKER-301` 关闭。

## 非目标

- 不批准 backend session、temporary document handle、native pointer、full BREP / TopoDS 或 persistent topo cache。
- 不做 current mismatch 判断。
- 不改 production code。
