# C12-M1 S2 范围准入与 blocker 矩阵

## 目标

把 S1 source candidates 路由成 scope review、blocker queue、non-goal registry 和 backend gap classification。S2 只做准入分类，不采 oracle，不改 C++。

## 分类规则

| 分类 | 准入条件 | S6 走向 |
| --- | --- | --- |
| `active_remaining_gap_oracle_blocked` | live capability 有非空 `remaining_gaps`，但 known gap route 是 oracle/product blocked。 | S3 复审；默认 retained。 |
| `representative_or_product_scope_candidate` | capability 是 representative subset、fallback metadata 或产品边界候选。 | S4 复审；需要产品授权和 expected 才能开代码。 |
| `historical_narrowed_or_non_parity` | `remaining_gaps=[]`，但存在 narrowed/historical native evidence。 | S5 复审；需要 stable oracle/current mismatch 才能重开。 |
| `non_goal` | GUI、session、persistent state、backend cache、adapter repair 等。 | 保留 forbidden claim。 |
| `implementation_candidate` | 有 source authority、stable expected/current mismatch、request-local 边界和 focused test route。 | S6 写下一包代码落点。 |

## 必须回写的矩阵行

- `C12M1-SCOPE-001..401`
- `C12M1-BLOCKER-201`
- `C12M1-NG-001..008`
- `C12M1-CAT-001..005`
