## S4 结论

- S4 起点确认 `pwd=/home/user/Chili3DProject/FreeCAD`，`HEAD=50a179ea1a`（`50a179ea1a docs: 完成 C12-M1 S3 CopyOnChange 复审`），起始工作区干净。
- FreeCAD authority 仍是 `src/Mod/Assembly/App/AssemblyObject.cpp`：`AssemblyObject::solve()` 在 request 内构建 MBD assembly，调用 `runPreDrag()` 后执行 `setNewPlacements()`；`setNewPlacements()` 以 `getMbdPlacement(mbdPart) * offsetPlc` 写回 Placement；`handleOneSideOfJoint()` 先用 `getGlobalPlacement(nullptr, ref)` 和 `getGlobalPlacement(part, ref).inverse()` 得到 moving-part-local marker，再应用 `data.offsetPlc * plc`。
- 当前 `cad-core/src/runtime/capability_contract.cpp` 与 `cad-core/tests/test_adapters.py` 一致：`assembly.ondsel_solver_adapter.status=covered_full` / `available=true`；`representative_solver_adapter.status=covered_representative` 但 `available=false`、`mode=fallback_metadata_only`，只保留 fallback metadata；`subshape_marker_placement.status=covered_representative_subset`，覆盖 object / Vertex / Edge / Face / mixed、`non_identity_bundled_offsetPlc_marker`、`placement_updates_native_parity`，`active_expected_count=28` 且 `remaining_gaps=[]`；`placement_writeback.status=covered_full`，覆盖 `documentObjectUpdates.action=assembly_set_placement`、multi-component / partial writeback 和 `bundled_offsetPlc_writeback`，`remaining_gaps=[]`。
- C9-M1 已把 marker/writeback 的早期产品边界关闭为 request-local no-code release gate；C9-M2 后续用 native expected 关闭 non-identity bundled `offsetPlc` marker/writeback 与 zero Angle fallback；C9-M3 / C9-M4 又把 DistanceType default boundary 扩面为 expected-backed supported rows。当前没有明确、产品批准、request-local 且 expected/current mismatch 的 Assembly 下一代表子集。
- 因此三项代码闸门没有同时成立：产品 scope 没有新批准，现有 FreeCAD authority 已落到 current covered subset，expected/current mismatch 不存在。S4 不推荐 C12-M2 implementation package；`C12M1-SCOPE-201` 关闭为 fallback metadata retained，`C12M1-SCOPE-202` 关闭为 expected-backed current-covered representative subset，`C12M1-BLOCKER-401`、`C12M1-CAT-002` 和 `C12M1-NG-003` 均关闭为 no-code/product-boundary retained 输入，交 S6 消费。
- S4 未修改 C++、未采 oracle、未新增 fixtures 或 expected，也未把 full Assembly solver、persistent solver state、cross-request session 或 fallback metadata 写成 native solver parity。
