# C12-M7 S5 发布闸门与后续分流

## 目标

消费 S0-S4，发布 C12-M7 最终出口并关闭队列。

## 出口

| 出口 | 条件 |
| --- | --- |
| `product_diagnostic_contract_published` | Native failure 仍成立，S2 批准 product contract，S3/S4 迁移和 focused tests 通过。 |
| `retained_historical_native_failure` | Native failure 仍成立，但 product contract 未获批准或迁移不完整。 |
| `implementation_candidate_required` | Native baseline 成功，stable expected 与 current CAD Core mismatch，且 mismatch 定位到 Geometry / PartDesign core。 |
| `no_code_retained` | 证据不足，不改代码和 expected。 |

## 操作

1. 更新 C12-M7 README、总入口、方案和矩阵。
2. 更新 `docs/CADCore12.0/README.md` 的 C12-M7 状态和重开条件。
3. 若最终出口是 implementation candidate，只写后续包范围，不在 S5 写几何 C++。
4. 重命名 S5 为 `【已实现】`。
