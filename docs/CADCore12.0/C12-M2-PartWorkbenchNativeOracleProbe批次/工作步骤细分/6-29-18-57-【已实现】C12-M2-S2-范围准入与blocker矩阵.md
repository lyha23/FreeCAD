# 【已实现】C12-M2 S2 范围准入与 blocker 矩阵

## 目标

把 S1 的 candidate row 过一遍 CAD Core 产品边界：哪些能作为 request-local native expected 采集，哪些只能保留为 GUI/session/native-hidden/helper blocker，哪些已属于 current-covered 或 non-goal。S2 仍不写代码。

## 准入规则

一个 row 只有同时满足以下条件，才能进入 S3-S5 native probe：

- FreeCAD source authority 已定位。
- 输入能由 request-local document graph / Part API fixture 表达。
- 输出能保存为稳定 expected artifact，不依赖跨请求 native document 或 GUI state。
- 有明确 current cad-core comparison path，或能在 S6 前建立该 path。
- blocker 不属于 crash、timeout、notCollected、TypeError、helper lifecycle 噪声本身。

## 执行步骤

1. 逐行更新 scope review matrix：`probe_admitted`、`needs_probe_design`、`native_hidden_blocked`、`helper_blocked`、`product_boundary_rejected`、`current_covered`。
2. 把 GUI/session/persistent geometry/cross-request cache 相关行为写入 non-goal registry。
3. 把 FreeCADCmd、collector schema、artifact location、native-hidden、helper lifecycle、current comparison 等阻塞写入 blocker queue。
4. 更新 backend gap classification，默认保持 `oracle_probe_candidate` 或 `retained_no_expected`，不得写成代码实现候选。
5. 如果某 family 太宽，记录后续拆分规则，但不删除该 family 的基线 row。
