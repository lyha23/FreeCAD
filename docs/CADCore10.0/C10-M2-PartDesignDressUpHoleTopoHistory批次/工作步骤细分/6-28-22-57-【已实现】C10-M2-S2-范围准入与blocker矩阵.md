## 分类规则

| 路由 | 进入条件 | 下一步 |
| --- | --- | --- |
| `baseline_frozen_s0` | S0 已冻结起点 | S6 release gate 复核即可。 |
| `oracle_candidate` | 有 FreeCAD authority，但需要 native expected 或 checked-in expected 证明行为 | S3/S4/S5 采集或复核 evidence。 |
| `current_mismatch_candidate` | 有 expected / focused test，但还没比较 current | S3/S4/S5 比较 current。 |
| `backend_gap_candidate` | S3-S5 证明 current mismatch | S6 落 C++ / tests。 |
| `diagnostic_retained` | 语义无法 request-local 支持或需要用户重选 | S6 发布诊断边界。 |
| `notCollected` | FreeCAD 行为不可观察或尚未采集 | 不实现，除非先补 oracle。 |
| `diagnostic_non_goal` | 本包排除 | 只记录 reopen condition。 |

## 必须回写的矩阵行

- `scope_review_matrix`：每个 scope 必须有合法 `current_status`、`next_step` 和 `close_condition`。
- `blocker_queue`：每个 blocker 必须指向至少一个 scope。
- `non_goal_registry`：每个 non-goal 必须写清用户 / 协议行为和 reopen condition。
- `backend_gap_classification`：不能出现没有 FreeCAD authority 和 current mismatch 的 `backend_gap_requires_implementation`。
