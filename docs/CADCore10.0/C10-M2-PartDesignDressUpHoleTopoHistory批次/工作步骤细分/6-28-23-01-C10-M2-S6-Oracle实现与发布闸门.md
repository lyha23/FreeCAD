## 目标

## 消费规则

| 输入状态 | S6 处理 |
| --- | --- |
| `backend_gap_candidate` | 必须有 FreeCAD authority + current mismatch；落 C++ / focused test / capability docs。 |
| `current_mismatch_candidate` | 先完成 comparison；不能跳过 evidence 直接实现。 |
| `notCollected` | 不实现；转 oracle 补采或 retained diagnostic。 |
| `diagnostic_retained` | 发布诊断边界，写清 reopen condition。 |
| `no_gap` / `expected_backed_no_gap` | 发布 no-code release gate。 |
| `release_gate` | 确认 docs、capability、tests 和 queue 状态一致。 |

## 禁止 shortcut

- 不在 adapter、JSON parser 或 export 层写业务修正。
- 不按 raw `FaceN`、bbox、面积、长度、顺序、source index、fixture 名称、几何类型组合或输出排序选 face / edge。
- 不把 `notCollected`、oracle-blocked 或 diagnostic-only 行转成 supported。
- 不引入跨请求 shape / BREP / NamedShape / ElementMap cache。
