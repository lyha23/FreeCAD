# 【已实现】C10-M3-S5 前端协议诊断与 non-goal 边界专项复审

## 目标

复核 `elementReferenceUpdates`、single-subshape `ReferenceShadow.brep` 例外、frontend graph update 建议和 non-goal registry。S5 要确保 C10-M3 即使打开 recovery 实现，也不突破 stateless CAD Core 边界。

## 协议边界

| 项 | 允许 | 禁止 |
| --- | --- | --- |
| `ReferenceShadow.brep` | 只作为被引用单个 subshape 的旧几何快照 evidence | 不作为建模输入、不保存完整对象 BREP。 |
| `elementReferenceUpdates` | 返回前端可选择回写的 graph update 建议 | 后端不持久化 DocumentObject graph 或 geometry session。 |
| split / deleted diagnostic | 发布 structured diagnostic、reason、candidate ambiguity | 不猜 raw `FaceN`、source index、bbox、面积、输出顺序。 |
| adapter | 做协议转换 | 不承载 FreeCAD 业务恢复逻辑。 |

## 必须回写的矩阵行

- `C10M3-SCOPE-202`：关闭为 `diagnostic_retained`、`no_gap` 或 evidence-backed `backend_gap_candidate`。
- `C10M3-SCOPE-301`：关闭为 `release_gate`、`diagnostic_retained` 或 S6 implementation row。
- `C10M3-BLOCKER-501`：S5 完成后改为 `closed_s5` 或 evidence-backed S6 implementation row。
- `C10M3-CAT-103`：按 protocol / diagnostic boundary 改为 `diagnostic_retained`、`no_gap` 或 `backend_gap_candidate`。
- `C10M3-NG-001` 到 `C10M3-NG-007`：确认每个 non-goal 的 reopen condition 仍准确。

## S5 收口结果

- 结论：`C10M3-SCOPE-202=diagnostic_retained`，`C10M3-SCOPE-301=release_gate`，`C10M3-BLOCKER-501=closed_s5`，`C10M3-CAT-103=diagnostic_retained`。
- current `cad-core` 仍把 `elementReferenceUpdates` 作为前端可选择回写的 request-local graph update 建议；`cad-core/include/cad_core/runtime/element_reference_update.h` 与 `cad-core/src/runtime/element_reference_update.cpp` 只组装 `SubList`、`StableSubList`、`ShadowSub`、`ReferenceShadow`、label/document rename 等协议字段，不持久化后端 geometry session。
- `ReferenceShadow.brep` 仍只是单个旧 subshape snapshot evidence：`cad-core/include/cad_core/app/property_links.h` 把它建模为 `ReferenceShadow` 的可选字段，`cad-core/src/part/topo_shape_reference.cpp::recoverReferenceShadowSubshape()` 只在 BREP / fingerprint 唯一匹配时恢复；unsupported、split、deleted、ambiguous 都保持 diagnostic / reselect，不猜 raw `FaceN`、bbox、面积、顺序、source index 或 fixture 名称。
- adapter 边界保持不变：`cad-core/tests/test_adapters.py` 约束 adapter stateless result channel、`ReferenceShadow.brep_single_subshape_only`、`adapter_publishes_contract_metadata_only` 和 diagnostic codes；adapter 只发布协议 metadata，不做 output repair。
- `C10M3-NG-001..007` reopen condition 已复核：raw geometry selector 永久禁止；cross-request cache 仍禁止；CopyOnChange 继续属于独立 DTO 包；full object BREP / TopoDS persistence 只有显式架构审批才能重开；GUI 不属于 cad-core；stale `ReferenceShadow` supported 仍要求 native observable evidence 加 current mismatch；adapter output repair 永久禁止。
- S5 未运行 FreeCADCmd，未采集 oracle / expected，未修改 `cad-core/src`、tests、fixtures、capability 或 adapter protocol，未新增 implementation row。
