消费 S3-S5 证明过的 `native_observable`、`backend_gap_candidate`、`notCollected`、`diagnostic_retained` 和 `release_gate` 行。S6 要么对 evidence-backed mismatch 落 C++ / focused tests，要么发布 no-code retained diagnostic；不得把未证明的候选写成实现完成。

## 消费规则

| 输入状态 | S6 处理 |
| --- | --- |
| `backend_gap_candidate` | 必须有 FreeCAD authority + native observable expected + current mismatch；落 C++ / focused tests / capability docs。 |
| `native_observable` | 若 current 无 mismatch，发布 no-gap；若有 mismatch，进入 implementation row。 |
| `current_comparison_pending` | 退回 S4；不能跳过 comparison。 |
| `notCollected` | 不实现；转 oracle 补采或 retained diagnostic。 |
| `diagnostic_retained` | 发布诊断边界，写清 reopen condition。 |
| `release_gate` | 确认 docs、capability、tests 和 queue 状态一致。 |

## 发布审计

- 若无 `backend_gap_candidate`：发布 no-code retained diagnostic，关闭或重新路由 `C10M3-BLOCKER-301`、`C10M3-BLOCKER-401`、`C10M3-BLOCKER-501`、`C10M3-BLOCKER-601`。
- 若有 implementation row：提交前必须有相邻 C++ 注释标注 FreeCAD 依据，focused tests 覆盖 native observable recovery 和 negative diagnostic。
- README、总入口、工作步骤总入口、矩阵、capability / docs 状态必须与 S6 裁决一致。
- S6 完成后 goal 队列必须为空；否则写清下一批 blocker，而不是把 S6 标为已实现。

## S6 收口结果

- 裁决：docs-only no-code retained diagnostic / release gate。S3-S5 未产生 `backend_gap_candidate`、`backend_gap_requires_implementation` 或 implementation row，因此本轮不打开 C++、fixtures、expected、capability 或 adapter protocol gate。
- S3 消费结果：`C10M3-SCOPE-101=notCollected`，`C10M3-SCOPE-102=notCollected`，`C10M3-BLOCKER-301=closed_s3`，`C10M3-CAT-101=notCollected`。FreeCAD C++ 仍是 source authority，但当前 native probe 只能证明 FCStd/XML restore 与 recompute 可跑通，不能通过 Python API 观测 `ShadowSub`、`ReferenceShadow` 或 `getSubValues(false/true)` recovery evidence。
- S4 消费结果：`C10M3-SCOPE-201=release_gate`，`C10M3-SCOPE-202=diagnostic_retained`，`C10M3-BLOCKER-401=closed_s4`，`C10M3-CAT-102=release_gate`。因缺 C10-M3 native observable expected，current cad-core parser / recovery / diagnostics 不能被判为 FreeCAD mismatch。
- S5 消费结果：`C10M3-SCOPE-202=diagnostic_retained`，`C10M3-SCOPE-301=release_gate`，`C10M3-BLOCKER-501=closed_s5`，`C10M3-CAT-103=diagnostic_retained`。`elementReferenceUpdates` 仍是前端 graph update 建议，`ReferenceShadow.brep` 仍只允许 single-subshape evidence，split / deleted / ambiguous 继续发布 diagnostic / reselect。
- 发布关闭：`C10M3-SCOPE-401=release_closed`，`C10M3-BLOCKER-601=closed_s6`，`C10M3-CAT-104=release_closed`。C10-M3 队列关闭；reopen condition 仍是先取得 native observable `ShadowSub` / `ReferenceShadow` evidence，再证明 current cad-core mismatch。
- 非目标保持不变：不运行 FreeCADCmd，不采 oracle / expected，不删除 CopyOnChange retained gap，不把 `notCollected`、oracle-blocked 或 diagnostic-only 行改成 supported，不把 `ReferenceShadow.brep` 扩展成 full object BREP persistence。
