# C10-M3-S5 前端协议诊断与 non-goal 边界专项复审

## 目标

复核 `elementReferenceUpdates`、single-subshape `ReferenceShadow.brep` 例外、frontend graph update 建议和 non-goal registry。S5 要确保 C10-M3 即使打开 recovery 实现，也不突破 stateless CAD Core 边界。

## 协议边界

| 项 | 允许 | 禁止 |
| --- | --- | --- |
| `ReferenceShadow.brep` | 只作为被引用单个 subshape 的旧几何快照 evidence | 不作为建模输入、不保存完整对象 BREP。 |
| `elementReferenceUpdates` | 返回前端可选择回写的 graph update 建议 | 后端不持久化 DocumentObject graph 或 geometry session。 |
| split / deleted diagnostic | 发布 structured diagnostic、reason、candidate ambiguity | 不猜 raw `FaceN`、source index、bbox、面积、输出顺序。 |
| adapter | 做协议转换 | 不承载 FreeCAD 业务恢复逻辑。 |

## 必须回写的矩阵行

- `C10M3-SCOPE-202`：关闭为 `diagnostic_retained`、`no_gap` 或 evidence-backed `backend_gap_candidate`。
- `C10M3-SCOPE-301`：关闭为 `release_gate`、`diagnostic_retained` 或 S6 implementation row。
- `C10M3-BLOCKER-501`：S5 完成后改为 `closed_s5` 或 evidence-backed S6 implementation row。
- `C10M3-CAT-103`：按 protocol / diagnostic boundary 改为 `diagnostic_retained`、`no_gap` 或 `backend_gap_candidate`。
- `C10M3-NG-001` 到 `C10M3-NG-007`：确认每个 non-goal 的 reopen condition 仍准确。
