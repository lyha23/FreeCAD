## 状态词典

| 状态 | 用法 |
| --- | --- |
| `baseline_frozen_s0` | S0 冻结起点和发布口径。 |
| `closed_s0` | 只表示 S0 文档 / 矩阵基线冻结完成，不表示功能 supported。 |
| `source_audit_pending` | S1 待读 FreeCAD / cad-core source authority。 |
| `native_oracle_candidate` | 需要 FreeCADCmd / FCStd / XML restore 证明可观察性。 |
| `current_comparison_pending` | 已有 native evidence 后，待比较 current cad-core。 |
| `backend_gap_candidate` | native evidence 与 current mismatch 同时存在后，S6 才能消费。 |

| `notCollected` | 尚无 native 可观察证据，不能实现。 |
| `release_gate` | S6 对 implementation / no-code / retained diagnostic 做发布收口。 |

## 验收标准

```bash
cd /home/user/Chili3DProject/FreeCAD
git status --short -uall

rg -n 'raw `FaceN`|bbox|source index|cross-request|CopyOnChange|diagnostic_retained' docs/CADCore10.0/C10-M3-ReferenceShadowShadowSubNativeRecovery准入批次
rg -n '[ \t]$' docs/CADCore10.0/C10-M3-ReferenceShadowShadowSubNativeRecovery准入批次 docs/CADCore10.0/README.md

```

`raw FaceN` / `bbox` / `source index` / `cross-request` / `CopyOnChange` 检索用于确认禁止口径仍存在，不要求零匹配。trailing whitespace 检索退出码 1 表示无匹配，是通过。
