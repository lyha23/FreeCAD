## S6 裁决

**裁决：existing-code no-code release gate。**

本轮没有 `backend_gap_requires_implementation` row，也没有发现 S5 approved candidate 的 publication evidence 缺口；不修改 C++、tests、fixture 或 capability。C10-M1 关闭为发布闸门：S3/S4 的 FaceMaker / WireJoiner C++ gate 保持关闭，S5 的 without-ReferenceShadow selector 只发布当前 recompute request-local `Sketch.InternalShape` `NamedShape` / `ElementMap` 唯一解析 `InternalFaceN` 的路径。

审计证据：

- `cad-core/src/part_design/profile_resolver.cpp::resolveInternalFaceStableSubname()` 要求 `Sketch.InternalShape` `NamedShape`、`elements`、`elementMap` 和非空 `internalShape` 全部存在；解析失败、split、deleted、non-face 或 subshape missing 会走 diagnostic，不回退 raw `FaceN`。
- `cad-core/src/part_design/profile_resolver.cpp::resolveSketchInternalFaceProfile()` 只接受单个 request-local `InternalFaceN`；without `ReferenceShadow` 的 non-internal stable subname 继续报 `unsupported_stable_subname`。
- `cad-core/src/runtime/reference_resolution.cpp` 只有在 `ReferenceShadow` lifecycle 存在并验证成功时才执行 recovery / update；`cad-core/src/runtime/element_reference_update.cpp` 只在 reference update 中发布 `SubList`、`StableSubList`、`ShadowSub`、`ReferenceShadow`。
- `cad-core/src/runtime/capability_contract.cpp` 仅发布既有 link property fields、diagnostics 和 `Profile.SubList=InternalFaceN` 能力；未声明 raw `FaceN` alias、geometry guessing 或 cross-request cache support。
- focused tests 已覆盖 accepted selector、missing evidence diagnostic、ReferenceShadow / ShadowSub recovery、split / deleted / ambiguous retained diagnostics、C API update fields 和 capability schema。关键锚点为 `cad-core/tests/test_p5_sketch.py`、`cad-core/tests/test_p6_topology.py`、`cad-core/tests/test_adapters.py`。

轻量抽样：

- `./build/cad-core recompute fixtures/p5/pad-internal-face-stable-sublist.json --output /tmp/c10m1-s6-stable-sublist.result.json`：公开结果 `diagnostics=[]`、`elementReferenceUpdates=[]`。
- `CAD_CORE_TEST_LEGACY_OUTPUT=1 ./build/cad-core recompute fixtures/p5/pad-internal-face-stable-sublist.json --output /tmp/c10m1-s6-stable-sublist.legacy.json`：legacy 结果 `Pad.status=ok`，`Sketch.InternalShape.element_map["InternalFace1"]="InternalFace1"`，且 `elementReferenceUpdates=[]`。

发布边界：

- pure without-ReferenceShadow `Profile.StableSubList=InternalFaceN` 不要求、也不发布 `elementReferenceUpdates`。
- 只有 ReferenceShadow lifecycle / 恢复证据存在时才发布 `SubList`、`StableSubList`、`ShadowSub`、`ReferenceShadow`。
- one-to-many、missing child-wire、summary-only、deleted source、raw `FaceN`、bbox / 面积 / outer-wire count / source index / split order / output order 仍是 retained diagnostic 或 non-goal。
