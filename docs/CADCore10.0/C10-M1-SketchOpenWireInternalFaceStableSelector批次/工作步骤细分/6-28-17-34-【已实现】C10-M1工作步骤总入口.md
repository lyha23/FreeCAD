## 执行顺序

1. 先做 S0，冻结 live baseline、允许声明和 forbidden claims。
2. S1 只读 FreeCAD source 与 current cad-core，不采 oracle，不改 C++。
3. S2 完成 scope / blocker / non-goal / backend-gap 初始路由。
4. S3 采集或复核 near-tangent / coincident-edge native oracle。
5. S4 复核复杂 open-wire 与 WireJoiner ledger。
6. S5 决定 InternalFace stable selector 是否可打开 request-local gate。
7. S6 只消费已证明的 implementation row 或 retained diagnostic row。
