## 分类规则

| 状态 | 使用条件 | 下一步 |
| --- | --- | --- |
| `native_oracle_required` | 需要 FreeCADCmd / native probe 证明行为 | 交 S3 或 S4。 |
| `current_mismatch_candidate` | 已有 oracle 或明确 current mismatch 线索 | 交 S6 前复核。 |
| `backend_gap_candidate` | 可能实现，但证据尚不足 | S3-S5 前不得落代码。 |
| `diagnostic_retained` | 多解 / 缺证据 / not serializable，需要保持显式诊断 | 交 S5/S6 发布。 |
| `diagnostic_non_goal` | Solver、GUI、cache、guessing 等明确排除 | 写 non-goal registry。 |
| `release_gate` | capability、diagnostic、test、docs 发布一致性 | 交 S6。 |
| `notCollected` | oracle 尚未采集或环境阻断 | 只能补 oracle 或保留 blocker。 |
