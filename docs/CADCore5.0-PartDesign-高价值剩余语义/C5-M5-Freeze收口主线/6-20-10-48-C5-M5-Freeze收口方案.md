# C5-M5 Freeze 收口方案

## 目标

C5-M5 只做阶段收口，不新增大语义。它负责把 C5-M1 到 C5-M4 的实现状态、deferred diagnostics、non-goals、fixtures、expected、capabilities 和测试结论同步到一致状态。

## 收口项

- 全局 `cadcore5_blocker_queue.tsv` 和 package-local blocker 队列。
- `cadcore5_scope_review_matrix.tsv`、`cadcore5_fixture_oracle_matrix.tsv`、`cadcore5_non_goal_registry.tsv`。
- `cad_core_capabilities_json()` 中 PartDesign 相关 capability metadata。
- `cad-core/fixtures/c5m*` 和 expected 文件。
- `tests.test_p7_features`、`tests.test_expected_fixtures`、`tests.test_adapters`。
- freeze summary 文档。

## 不做

- 不在 freeze 步骤新增新的 PartDesign feature 支持。
- 不放宽 expected fixture。
- 不把未实现 advanced branch 改成 supported。
- 不做全量 FreeCAD 构建。
