# C5-M15-S6 Oracle 实现与发布闸门

## 目标

消费 C5-M15 的 `pending_native_oracle`、`pending_backendGap` 和 `releaseGate` 行，完成 FreeCADCmd expected、cad-core C++、fixtures、focused tests、capability/docs 和验收记录闭环。

## 队列消费规则

- 只消费 `C5M15-BLK-101`、`201`、`202`、`301`、`302`、`501`。
- `C5M15-NG-*` 不进入实现队列。
- 如果 `TangentPlane` oracle 或 normal/tangent 复刻失败，必须把失败项改成 precise blocker 并保留 `Translate` / `ThreePoints*` 的可关闭实现；不得把整个包写成 supported。
- 不创建 cad-core-output-derived expected。
