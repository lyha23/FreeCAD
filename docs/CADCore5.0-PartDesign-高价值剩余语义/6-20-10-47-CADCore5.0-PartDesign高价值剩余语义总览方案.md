# CADCore5.0 PartDesign 高价值剩余语义总览方案

## 目标

CADCore5.0 的本包目标不是开启完整 FreeCAD 5.0 迁移，而是在 CADCore4.0 已 freeze 的基线上，继续补齐前端 CAD 运行时最有价值的 PartDesign 剩余语义。

本阶段仍以本仓库 FreeCAD `src/` 为语义来源，以 `cad-core/` 为无状态几何计算核心。前端保存完整 `DocumentObject graph`；后端每次只根据请求 graph、目标和运行时参数重算 shape、mesh、subshape、topo naming、引用更新建议与 diagnostics。

## C4.0 基线

| 领域 | C4.0 状态 | C5 入口 |
| --- | --- | --- |
| Revolution / Groove | `Type=Angle`、axis-based Body replay 和 `maker_history:revolve` 已 expected-backed；TwoAngles / ThroughAll / UpTo / Profile subshape / FuseOrder 仍 deferred | C5-M1 |
| Boolean | `Fuse` / `Cut` / `Common` Body tool、BaseFeature、single-solid diagnostic 和 boolean maker history 已 expected-backed；AllowCompound / multi-solid / multi-body ownership 仍 deferred | C5-M2 |
| Loft | Additive / Subtractive full-profile + one Sketch section Body replay 已 expected-backed；explicit selection、Closed multi-section、multi-wire ordering、AllowCompound、sewing MapperHistory 仍 deferred | C5-M3 |
| Pipe | Additive / Subtractive full-profile + single Sketch spine Body replay 已 expected-backed；Sections、AuxiliarySpine、Binormal、Transformation、Transition、SpineTangent、sewing MapperHistory 仍 deferred | C5-M3 |
| Datum Attachment | Datum placement、link、relink 和 Body Origin role 已支持；active `AttachmentSupport` / `MapMode` 当前是 locatable deferred diagnostic | C5-M4 |

## 范围

5.0 本包只接收满足以下条件的任务：

- 属于 PartDesign feature family、Body chain、AddSubShape、BaseFeature、Group、Tip replacement、maker history、ElementMap、引用恢复或下游 recompute 所需语义。
- 能从 `src/Mod/PartDesign/App`、`src/Mod/Part/App` 或 `src/App` 找到明确 FreeCAD 源码依据。
- 能落到 `cad-core/src/part_design`、`cad-core/src/part/topo_shape*`、`cad-core/src/runtime`、`cad-core/src/app`、`cad-core/tools/collect_freecad_expected.py` 或 `cad-core/src/adapters/c_api/c_api.cpp`。
- 能用 native expected fixture、focused tests、capability metadata 或稳定 diagnostic 验收。

## 非目标

- FreeCAD GUI、ViewProvider、TaskPanel、command panel 和交互式编辑器状态。
- 完整 FreeCAD PartDesign Workbench 一次性迁移。
- 用 cad-core 当前输出倒推 expected。
- 在 adapter 中写 PartDesign 业务语义。
- 用输出顺序、bbox、fixture 名称或几何相似度猜 topo alias。
- 跨请求后端 document session 或除 `ReferenceShadow.brep` 单 subshape snapshot 外的长期 BREP 状态。

## 阶段拆分

| 阶段 | 主线 | 目标 |
| --- | --- | --- |
| C5-M0 | 范围审计与基线重建 | 复核 C4 freeze PartDesign rows，建立 C5 source / scope / fixture / non-goal / blocker 矩阵 |
| C5-M1 | Revolution / Groove 参数补完 | 补 `TwoAngles`、`ThroughAll`、`UpTo*`、Profile subshape 和 `FuseOrder=FeatureFirst` 的 oracle-first 主线 |
| C5-M2 | Boolean / Body ownership | 补 AllowCompound、multi-solid policy、multi-body ownership、Body Group / BaseFeature 更新和稳定 failure diagnostics |
| C5-M3 | Loft / Pipe 高级分支 | 补 Loft closed / multi-section / multi-wire / sewing history 与 Pipe Sections / orientation / Transformation / Transition 分支 |
| C5-M4 | Datum Attachment 引用稳定 | 评估非 GUI AttachEngine map-mode solver 是否进入 CAD Core，并补 AttachmentSupport / MapMode / downstream reference owner |
| C5-M5 | Freeze 收口 | 同步 docs、matrices、capabilities、expected fixtures、diagnostics 和 focused regression，形成 PartDesign 5.0 freeze |

## 推进规则

- 每个专题包先读 FreeCAD 源码，记录调用链，再写 cad-core 落点和 fixture 草案。
- 每个实现批次必须是最小完整语义批次，不能只挑单个易过 fixture。
- 对每个 supported row 同步 capability metadata、fixture、focused tests 和 remaining boundary。
- 暂不支持的分支必须变成 locatable diagnostic 或 non-goal registry 行，不得恢复 broad `full_part_design` gap。
- 只要涉及 topo naming、ElementMap 或 sewing / boolean / revolve maker history，不得在 feature executor 或 adapter 中靠输出修正替代 `topo_shape` / MapperHistory 路径。
