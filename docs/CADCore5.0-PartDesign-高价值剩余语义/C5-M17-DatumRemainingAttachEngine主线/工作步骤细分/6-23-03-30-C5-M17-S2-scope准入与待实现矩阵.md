# C5-M17-S2 scope 准入与待实现矩阵

## 目标

把 S1 source candidates 路由到可实现 backendGap、later package、source-unclear blocker 或 non-goal，避免 S6 过度声明 remaining modes。

## 准入规则

| 分类 | 条件 | 本包处理 |
| --- | --- | --- |
| `pending_backendGap` | 同一 FreeCAD conic landmark route，可采集 native expected | `Directrix1/2`、`Asymptote1/2`、`Focus1/2` |
| `laterPackage` | 实现 owner 明确但不同调用链 / 状态机 | `Folding` |
| `sourceAuditRequired` | route 存在但 DTO/API 与 expected 风险较大 | `IntersectionPoint` |
| `laterSurfacePackage` | 属 surface tangent / TangentPlane adjacent family | `TangentU/V` |
| `nonGoal` | GUI/session/cross-request state | GUI Attachment editor、backend session |

## 必做

1. 更新 package-local backend gap classification。
2. 更新 package-local blocker queue。
3. 更新 fixture/oracle matrix，明确 S6 只采集 conic landmark fixture。
4. 更新 non-goal registry，写清 excluded family reopen condition。
5. 同步根矩阵中的 C5-M17 状态。
