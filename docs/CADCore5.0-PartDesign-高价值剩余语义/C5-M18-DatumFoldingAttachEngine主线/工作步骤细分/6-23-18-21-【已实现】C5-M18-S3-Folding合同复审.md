# 【已实现】C5-M18-S3 Folding 合同复审

状态：`done_s3_closed`

## 合同

| 合同点 | C5-M18 行为 |
| --- | --- |
| support count | 必须有四条 resolved supports |
| support type | 每条 support 必须解析为 straight `TopoDS_Edge` line |
| support order | `edgeA`、`axisA`、`axisB`、`edgeB`，顺序不可重排 |
| shared vertex | 四条 line 必须共享同一个顶点 |
| direction sign | direction 统一从共享点向外 |
| fold angle | 等价 `calculateFoldAngle(axisA, axisB, edgeA, edgeB)` |
| final placement | base=shared vertex, x-axis=axisA direction, normal=rotated normal reversed |

## Diagnostics

| failure | diagnostic |
| --- | --- |
| missing fourth support | `attachment_support_invalid_shape` |
| non-straight support | `attachment_support_invalid_shape` |
| disconnected supports | `no_intersection` |
| parallel axes | `attachment_parameter_invalid` |
| axisA / edgeA parallel | `attachment_parameter_invalid` |
| invalid folding cosine | `attachment_parameter_invalid` |
