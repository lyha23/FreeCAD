## 队列消费规则

- 必须在 C5-M15 S6 已关闭后执行。
- 只消费 `C5M16-BLK-101`、`201`、`301`、`401`、`501`。
- `C5M16-NG-*` 不进入实现队列。
- 若某一 curve mode 无法稳定采集 oracle，必须拆 precise blocker，不得把整个 package 写成 supported。
- 不创建 cad-core-output-derived expected。
