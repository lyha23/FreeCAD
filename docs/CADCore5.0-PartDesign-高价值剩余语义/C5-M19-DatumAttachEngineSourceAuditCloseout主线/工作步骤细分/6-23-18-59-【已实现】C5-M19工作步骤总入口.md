## 执行顺序

1. S0 冻结：只审计 `TangentU`、`TangentV`、`IntersectionPoint`，不重开 C5-M14~M18。
2. S1 查源码：enum/name 表、`EnableAllSupportedModes()`、各 engine 构造器和 `_calculateAttachedPlacement()` 分支。
3. S2 分类：有 executable route 才进 backendGap；否则转 source-audited non-goal。
4. S3 复审 `TangentU/V`：它们只是 `mmTangentPlane` 内部 tangent direction，不是可选 MapMode。
5. S4 复审 `IntersectionPoint`：它没有 Point engine 注册/分支；`IntersectionLine` 是另一个已支持 DatumLine route。
6. S5 同步 capability / request-local 边界。
7. S6 验证 adapter capability、TSV、queue 和 diff。
