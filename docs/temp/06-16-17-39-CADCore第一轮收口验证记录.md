# CAD Core 第一轮收口验证记录

## 当前验证基线

本轮已恢复 `cad-core` 在当前 Linux/WSL 环境下的配置、构建和 MVP 测试：

- `cmake -S . -B build`：通过。
- `cmake --build build`：通过。
- `python3 -m unittest tests/test_mvp.py`：通过，1 个测试 OK。

本机环境关键信息：

- 系统可用 Linux OCCT 头文件与库：`/usr/include/opencascade`、`/usr/lib/x86_64-linux-gnu/libTK*.so`，版本为 OCCT 7.5.1。
- `PATH` 中同时存在 Windows FreeCAD LibPack 路径，原 CMake 会误拾取 `/mnt/c/.../LibPack.../cmake`，导致链接 `.dll` 和 `advapi32.lib` 等 Windows 库失败。
- 仓库内已有 `src/3rdParty/json/single_include/nlohmann/json.hpp`，已作为 `cad-core` 的 `nlohmann/json.hpp` 查找入口。

## 本轮完成

- `cad-core/CMakeLists.txt` 增加 OpenCASCADE 查找兜底：CONFIG package 可用时沿用；Linux 下若 CONFIG 路径来自 `/mnt/c` Windows LibPack，则改用系统 OCCT include/lib。
- `cad-core/CMakeLists.txt` 增加仓库内 vendored `nlohmann/json.hpp` 查找路径。
- 补齐 Linux OCCT 7.5 下需要的直接头文件 include：`gp_Pln.hxx`、`gp_Circ.hxx`。
- `shape_exporter.cpp` 对 `TopTools_FormatVersion.hxx` 做条件编译：新 OCCT 继续使用显式 BREP format version；旧 OCCT 7.5 回退到旧版 `BRepTools::Write(shape, file)`。

以上改动只解决构建环境和 OCCT 版本兼容，不改 CAD Core 业务语义、fixture expected、executor 几何流程或输出端修剪逻辑。

## 真实失败清单

### diagnostics

命令：

```bash
cd /home/user/Chili3DProject/FreeCAD/cad-core
python3 -m unittest tests/test_diagnostics.py
```

结果：10 个测试中 1 个失败。

- `p8/part-boolean-fragments-shell-split`：实际 diagnostics 为 `['execution_failed', 'execution_failed']`，expected 为 `[]`。运行时输出含 `File was not written with this version of the topology`，当前更像 OCCT 7.5 读取既有 BREP / topology 版本不兼容或 oracle 环境差异，不能直接归类为 CAD Core 业务实现失败。

### feature flows

命令：

```bash
cd /home/user/Chili3DProject/FreeCAD/cad-core
python3 -m unittest tests/test_feature_flows.py
```

结果：30 个测试中 27 个失败。

失败集中在 bbox 对比，典型差异为 `-0.10000010000000001 != 0.0`、`1.8999999 != 2.0`、`19.8999999 != 20.0`。当前应先归类为 OCCT 7.5 构建基线与 expected 采集基线不一致，或 fixture expected 对 OCCT 版本敏感；本轮不应通过放宽断言、改 expected、几何类型排序或输出端修剪来掩盖。

受影响 fixture 分组：

- `p2`：`rect-pad-pocket`、`body-basefeature-pad`。
- `p3a`：`pocket-through-all`、`pocket-up-to-face`、`pocket-up-to-shape-solid`、`pocket-up-to-shape-face`、`pocket-up-to-shape-multi-face`、`pad-up-to-face`、`pad-up-to-shape-multi-face`。
- `p3b`：`pocket-two-sides-length`、`pocket-symmetric-length`、`pad-custom-vector`、`pocket-custom-vector`、`pad-reference-axis`、`pad-reference-axis-edge`、`pocket-body-placement`、`pocket-length-taper`、`pad-two-sides-up-to-face1`、`pad-two-sides-up-to-shape1`、`pad-two-sides-up-to-face2`、`pad-two-sides-up-to-shape2`。
- `p4`：`body-link-list`、`part-placement-body`、`sketch-placement-pocket`、`typed-property-pad`、`datum-plane-support`、`datum-line-reference-axis`。
