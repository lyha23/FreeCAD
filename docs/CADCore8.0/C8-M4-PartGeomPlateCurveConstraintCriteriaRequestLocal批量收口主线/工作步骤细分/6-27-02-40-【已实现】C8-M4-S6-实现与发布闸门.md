## S6 实现结果

- `cad-core/include/cad_core/part/part_geomplate.h::GeomPlateCurveConstraintSource` 新增 `g0Criterion` / `g1Criterion` / `g2Criterion` optional 字段，并标注 FreeCAD getter、PointConstraint analog 与 OCCT criteria-law 依据。
- `cad-core/src/part/part_geomplate.cpp::readCurveConstraints()` 现在对 `CurveConstraints.SubSet[].G0Criterion/G1Criterion/G2Criterion` 做 finite-number validation；合法值进入 Curve source，非法类型或非 finite number 走 `invalid_parameter`。
- `cad-core/src/part/part_geomplate.cpp::addCurveConstraint()` 现在把 finite-number criteria 映射成 OCCT `Law_Constant`，并调用 `GeomPlate_CurveConstraint::SetG0Criterion()` / `SetG1Criterion()` / `SetG2Criterion()`；source evidence 回写 `g0_criterion` / `g1_criterion` / `g2_criterion`。
- 新增 `cad-core/fixtures/c8m4/part-geomplate-curve-custom-criteria.json`，同一 CurveConstraint 同时含 G0/G1/G2。该 fixture 使用 CurveOnSurface representative，因为 OCCT G1/G2 Curve criteria 要求 source curve on surface。
- `cad-core/fixtures/c5m7/part-geomplate-curve-criteria-diagnostic.json` 改为 invalid criteria 类型负例；对应 expected 和 tests 断言 `invalid_parameter`，不再把合法 criteria 归为 `unsupported_curve_criteria`。
- `cad-core/src/runtime/capability_contract.cpp` 发布 `c8m4_curve_constraint_criteria_product_contract`；`curve_constraint_criteria_setters_not_implemented` 只保留为 native non-parity historical evidence，并带 delete / reopen condition。
- GUI / TaskPanel / ViewProvider、`PlateSurface.Curves` wrapper lifecycle、cross-request geometry cache、downstream Rust / frontend persistence 均保持 non-goal。

## implementation gate 打开时的执行顺序

1. 重新记录 live baseline 和当前队列。
2. 复核 `readCurveConstraints()`、`addCurveConstraint()` 和 tests 中的当前阻断。

4. 增加或更新 request-local fixture，至少覆盖同一 CurveConstraint 的 G0 / G1 / G2 全字段。
5. 更新 focused tests，断言 source evidence 中三项 criteria 存在且不再产生 `unsupported_curve_criteria`。

## S5 publication strategy

- S6 实现完成后，`cad-core` request-local CurveConstraint `G0Criterion` / `G1Criterion` / `G2Criterion` 发布为 `part_workbench.geomplate` product contract / supported capability。
- `curve_constraint_criteria_setters_not_implemented` 不得作为 active `remaining_gaps`。如仍保留，只能作为 FreeCAD native non-parity / historical evidence，并带 delete / reopen condition。
- FreeCAD native setter blocked 只代表 upstream/native parity blocked，不否定 cad-core request-local support。
- 合法 G0 / G1 / G2 finite-number 输入不应产生 `unsupported_curve_criteria`；invalid criteria 类型、缺失数值或非 finite-number 输入必须走显式 invalid finite-number diagnostic。
- GUI / TaskPanel / ViewProvider、`PlateSurface.Curves` wrapper lifecycle、cross-request geometry cache、downstream Rust / frontend persistence 均保持 non-goal，不写成本轮必须完成。
