## 执行顺序

1. 每一步开始前先执行 live baseline：`pwd`、`git rev-parse --short HEAD`、`git log -1 --oneline`、`git status --short -uall`。
2. 每一步先运行本目录 `step_goal_queue.py`，只处理当前第一个 pending 文件。
3. S0-S2 只允许文档和矩阵，不新增 fixtures / expected，不改 C++。
4. S3 可做 source 复核和可选 FreeCADCmd native probe；不得把 sandbox 内 Qt / FreeCADCmd 启动失败当成 semantic failure。
5. S4-S5 可以形成 implementation gate，但代码只能在 S6 落地。
6. S6 若打开代码闸门，必须同时补 C++、fixtures / tests、capability/docs 和验收记录；若不开代码闸门，必须说明 no-code 裁决证据。
