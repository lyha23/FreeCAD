# C8-M4-S6 实现与发布闸门

## 目标

按 S3-S5 的裁决执行最终闸门。如果 S4/S5 打开 implementation gate，S6 落 `cad-core` request-local CurveConstraint criteria 支持；如果没有打开，S6 做 no-code release gate 并保留 diagnostic。

## implementation gate 打开时的执行顺序

1. 重新记录 live baseline 和当前队列。
2. 复核 `readCurveConstraints()`、`addCurveConstraint()` 和 tests 中的当前阻断。
3. 修改 `cad-core/src/part/part_geomplate.cpp`，让 G0 / G1 / G2 criteria 进入 `GeomPlateCurveConstraintSource` 并复用 OCCT `SetG*Criterion` apply path。
4. 增加或更新 request-local fixture，至少覆盖同一 CurveConstraint 的 G0 / G1 / G2 全字段。
5. 更新 focused tests，断言 source evidence 中三项 criteria 存在且不再产生 `unsupported_curve_criteria`。
6. 更新 capability / diagnostics tests，把 active gap 和 non-goal 口径同步到 S5 裁决。
7. 更新本包矩阵、README、总入口和 `docs/CADCore8.0/README.md`，把已完成步骤按原时间前缀重命名为 `【已实现】`。

## no-code gate 时的执行顺序

1. 重新记录 live baseline 和当前队列。
2. 写明不开 implementation gate 的具体证据。
3. 保留 `unsupported_curve_criteria` 和 active narrowed gap，或按 S5 仅做 docs/capability publication 裁决。
4. 更新本包矩阵、README、总入口和 `docs/CADCore8.0/README.md`。
5. 队列清空后提交文档变更。
