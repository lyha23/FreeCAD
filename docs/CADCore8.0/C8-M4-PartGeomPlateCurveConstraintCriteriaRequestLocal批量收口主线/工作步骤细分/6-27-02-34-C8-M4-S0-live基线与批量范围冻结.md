## 状态词典

- `already_supported`：已有 expected-backed 或 focused-test-backed support。
- `request_local_backend_gap_candidate`：有 `cad-core` request-local DTO / OCCT 落点但当前 parser 或 capability 阻断。
- `native_oracle_blocked`：FreeCAD native wrapper 不可设置或 probe 不稳定，只能保留 boundary。
- `diagnostic_boundary_retained`：当前 diagnostic 仍正确，S6 不落代码。
- `capability_publication_gap`：代码已有支撑但 capability / tests / docs 仍保留 stale gap。
- `non_goal`：明确超出无状态 CAD Core。
- `split_required`：同轮批量风险过大，必须记录下一批范围和拆分理由。
