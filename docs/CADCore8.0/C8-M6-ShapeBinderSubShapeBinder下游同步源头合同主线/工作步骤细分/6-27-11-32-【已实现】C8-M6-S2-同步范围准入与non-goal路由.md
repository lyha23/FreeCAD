# 【已实现】C8-M6 S2 同步范围准入与 non-goal 路由

## 目标

把所有下游同步项按范围准入分类，避免把 C8-M2 已明确的 known gap 或持久化非目标误写成 supported 合同。

## 分类规则

| 分类 | 含义 | 后续动作 |
| --- | --- | --- |
| `sync_required_source_contract` | FreeCAD 仓库已验证，可作为下游同步合同 | 进入 S3-S5 发布。 |
| `known_gap_retained` | 当前仍是 C8-M2 known gap / oracle blocked | 保持 diagnostic，不进入 implementation gate。 |
| `release_gate_only` | 只需要验证 C8-M5 后合同没有漂移 | S6 release gate 关闭。 |
| `unexpected_mismatch` | current code、fixture、capability 或 docs 互相矛盾 | S6 必须改代码或刷新合同，不能文档关闭。 |
| `non_goal` | 本包明确不做 | 写入 non-goal registry。 |

## 必须回写的矩阵行

- `c8m6_downstream_sync_scope_review_matrix.tsv` 全部 scope 行。
- `c8m6_downstream_sync_backend_gap_classification.tsv` 全部 category 行。
- `c8m6_downstream_sync_non_goal_registry.tsv` 全部 non-goal 行。
- `C8M6-BLOCKER-201`

## 关键边界

- `copy_on_change_full_temporary_document_cache` 只能保持 `known_gap_retained`。
- C8-M5 的 `BodyBaseFeature` 裁决必须进入 fixture contract；不能把旧 expected 作为下游要求。
- C8-M5 的 `cycle_rejected_by_property_link` 必须进入 diagnostics contract；不能把 SubShapeBinder self-link 退回 generic `cycle_dependency`。
- request-local ElementMap / NamedShape 可以同步；跨请求持久 ElementMap / NamedShape 不可以同步。

## S2 分类结论

- `sync_required_source_contract`：`C8M6-SCOPE-101..104`、`C8M6-SCOPE-201..203`、`C8M6-SCOPE-301`。覆盖 TypeId / capability、request-local output、fixture seeds、C8-M5-current expected、BodyBaseFeature no-synthesis boundary 和 diagnostics vocabulary。
- `known_gap_retained`：`C8M6-SCOPE-204`。`copy_on_change_full_temporary_document_cache` 继续保留 C8-M2 `known_gap` / `oracle_blocked` 和 capability `remaining_gaps`。
- `release_gate_only`：`C8M6-SCOPE-001`、`C8M6-SCOPE-302`。只在 S6 验证 C8-M5 后合同、focused tests、expected fixture gate 和阶段回归没有漂移。
- `unexpected_mismatch`：S2 未发现 current code、fixture、capability 或 docs 矛盾；若 S3-S5 发现矛盾，必须交 S6 路由到明确 `cad-core` 落点，不能文档关闭。
- `non_goal`：下游仓库审计或修改、UI 展示策略、跨请求持久 full BREP / TopoDS_Shape / NamedShape / ElementMap / temporary cache、本步修改 `cad-core/src` / fixtures / tests / expected 均排除。
- `C8M6-BLOCKER-201` 已关闭；scope/category/non-goal 矩阵已清掉 `seed_pending`、`baseline_frozen` 和非标准分类。
