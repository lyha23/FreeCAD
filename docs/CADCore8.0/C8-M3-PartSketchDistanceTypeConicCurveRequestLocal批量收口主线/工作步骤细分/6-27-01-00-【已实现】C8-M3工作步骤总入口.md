## 执行顺序

1. 每一步开始前先执行 live baseline：`pwd`、`git rev-parse --short HEAD`、`git log -1 --oneline`、`git status --short -uall`。
2. 每一步先运行本目录 `step_goal_queue.py`，只处理当前第一个 pending 文件。
3. S0-S2 只允许文档和矩阵，不新增 fixtures / expected，不改 C++。
4. S3-S5 可以新增 oracle plan / probe / fixture 候选，但只有明确可实现的 request-local backend gap 才进入 S6。
5. S6 若打开代码闸门，必须同时补 C++、fixtures / expected、focused tests、capability/docs 和验收记录；若不开代码闸门，必须说明无实现缺口的证据。
