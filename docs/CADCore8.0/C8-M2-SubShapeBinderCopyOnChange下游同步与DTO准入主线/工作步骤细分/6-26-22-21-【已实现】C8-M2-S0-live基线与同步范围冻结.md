## 状态词典

- `already_supported`：C8-M1 已有 expected-backed 支持。
- `sync_required`：FreeCAD repo 只冻结下游同步合同，代码落到下游。
- `oracle_candidate`：需要 native probe 采集。
- `known_gap_retained`：当前 known_gap 保留，等待更强证据。
- `backend_gap_candidate`：有 FreeCAD source 与 current mismatch，但需要 S3/S6 裁决。
- `backend_gap_requires_implementation`：S3 expected 与 current mismatch 都成立，S6 才能打开。
- `diagnostic_non_goal`：明确不属于无状态 CAD Core 后端。
