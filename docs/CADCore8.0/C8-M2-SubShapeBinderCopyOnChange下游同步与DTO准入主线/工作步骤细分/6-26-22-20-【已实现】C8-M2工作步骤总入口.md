## 执行顺序

1. 每一步开始前先执行 live baseline：`pwd`、`git rev-parse --short HEAD`、`git log -1 --oneline`、`git status --short -uall`。
2. 每一步先运行本目录 `step_goal_queue.py`，只处理当前第一个 pending 文件。
3. S0/S1/S2 只允许文档和矩阵，不新增 fixtures / expected，不改 C++。
4. S3 可以新增 native probe / evidence fixture / known_gap expected，但不能改 runtime C++ 主路径。
5. S4/S5 只发布同步合同和 capability 边界；除非发现 capability/test 断言缺失，不改 C++。
6. S6 只有在 S3 证明 request-local CopyOnChange DTO 可实现时才打开 C++ implementation gate。
