## 派生规则

```text
open_wire_compound_legacy_helper_shape_wire_info_count
  = count(childWires where blocker == LegacyHelperShapeStillUsed)

open_wire_compound_helper_open_export_override_helper_shape_wire_info_count
  = count(childWires where blocker == LegacyHelperShapeStillUsed)
```

当前 P6 gate 要求全量 `cad-core/fixtures/p5/*.json` 的 generated/helper output 与
`LegacyHelperShapeStillUsed` 相关 summary 不再输出，
并且每个 `result_wire_producer_ledger_entries` 条目都是 `state == ExportedWithoutHelper`、
`blocker == None`，且与 open-export history 逐条一致。没有 `helper_open_export_override_source_edge_export_shape` 的 migrated slot
必须是 `SuperEdgeRoot` 或 `CurrentMemberChildWire` producer，并带 root producer evidence；旧
finder / helper shape 不能再作为任何 slot 的泛用输出 fallback。`generatedOpenExportShapeForSketchInternals()`
与中间态 `legacyResultSlotLocatorEdgesForDiagnosticsOnly()` 均已删除；`partial_shared_closed_wire`、
`consumed_open_cutter_graph`、`partial_junction_open_cutter` 与 `closed_wire_cycle` 均从 final
`EdgeInfo` / source lineage / closed-wire boundary / bounded-result evidence 直接建 binding。root/current-member
非 source-shaped slot 不再把 finder edge 写入 `openExportOverride`，`resultSlotEdge` 只保留为内部 child-wire 顶点证据。

## 清理顺序

1. 先新增 producer ledger。
2. 旧 counter 从 producer ledger 派生。
3. fixture 全绿后删除旧 counter 的主流程写入；当前 helper / legacy output 兼容 counter 已改为 blocker 派生。
4. 旧 finder 删除后只允许继续保留 producer ledger、history / ElementMap identity gate 与有限 blocker；不得恢复 helper/generated shape、result-slot finder、result-wire blocker summary 或 owner/search/exhaust 临时 JSON summary 作为验收入口。
