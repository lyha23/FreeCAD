### 当前落地边界（2026-06-03）

- 已落地：`ResultWireProducerKind`、`ResultWireProducerState`、`ResultWireBlocker`、`ResultWireProducerIdentity`、`ResultWireProducerLedgerEntry`。
- 已落地：`EdgeInfo::resultWireProducer`、`OpenWireCompoundWireInfo::resultWireProducer`、`WireJoinerOpenExportHistoryEntry::resultWireProducer`，以及 topo history JSON 中的 producer kind/state/blocker。
- 已落地：P0/P1 的 producer ledger 断言、M2S 的 ready/not-ready 分区断言、P3 的 unowned ready 子集 gate 和 `multi_member_root_direct_output_count == 0` 断言。
- 已落地：M2S source-shape gate 对 FreeCAD edge-level shared-vertex purge 语义和 child-wire / root-open member input 顶点 identity coverage 的检查；不满足时按 lifecycle 保留为 `SourceShapeIdentityNotReady` 或 `SourceShapeMemberVertexIdentityNotReady`，不切换输出。
- 已落地：P3 unowned-removal + member-suppressed current-member ready 子集输出切换；root `superEdge` 中匹配的 current-member edge 复用 child-wire / root-open member input 顶点 ledger 后进入 `ExportedWithoutHelper`。
- 已落地：P5 strict-source sidecar 子步。`helperOpenExportOverrideSourceLineageRemovedSourceEdgeInfo` 只能作为同 lineage 严格 Remove source 证据，不能把当前 target EdgeInfo 改判成 strict Remove source；缺少 removed-target evidence 的条目进入 `MissingRemovedTargetEvidence`，不再混入 generic full-evidence blocker。
- 已落地：P5 full-evidence source-shape 子步。`EdgeInfo` producer 输出不再直接替换为 raw source edge，而是用 producer edge curve 复用等价 result/helper 顶点，保持 fixture 顶点数稳定；foreign lineage 仍先于 sidecar evidence 被 blocker 拦截。
- 已落地：P5 live final-gate open edge 子步。`edgeInfoExportsOpenWireCompound()` 且未被 `buildClosedWire()` 消费的 helper slot 归类为 `LiveResetOpenEdge`；通过 source-shape / `noOriginal` purge gate 时输出 producer curve + result/helper 顶点，未通过时停在 `SourceShapeIdentityNotReady`。
- 已落地：P4 primary/secondary-removal current-member gate。primary 与 secondary root candidate 复用 P3 member suppression + child-wire identity gate；只有 root full evidence 且 source-shape gate 通过时输出 current-member child wire，当前重点 fixture 暂无 secondary 输出样本。
- 已落地：SuperEdgeRoot full evidence classifier 收敛。已有 root full evidence 的条目不再停在 `MissingFullAHistoryProducerEvidence` / `MissingAHistoryRemoveSource`，而是进入 `RootRemovedByUnownedBranch` / `RootRemovedByPrimaryBranch` / `RootRemovedBySecondaryBranch` 与后续 child-wire gate。
- 已落地：child-wire blocker summary 去重。若 child-wire producer 只是镜像同一个 EdgeInfo 的 blocker，不再重复计入 summary；member-suppressed 等 child-only `SourceShapeIdentityNotReady` 仍保留。
- 已落地：`MissingRemovedTargetEvidence` 有限 blocker。已有 Remove-source 证据但当前 helper-selected `EdgeInfo` 缺少 removed-target evidence 的条目独立归类，当前重点 fixture 的 `MissingFullAHistoryProducerEvidence` 已归零。
- 已落地：source-shape purge 有限 blocker 按 lifecycle 分流。live final-gate producer 若会被 FreeCAD `getOpenWires(noOriginal=true)` 作为原始线 purge，进入 `LiveResetSourceShapeWouldPurgeOriginal`；branch / root-open current-member child-wire 若会被同一 gate purge，进入 `CurrentMemberSourceShapeWouldPurgeOriginal`。宽泛 `SourceShapeWouldPurgeOriginal` 仅保留为兜底桶，当前重点 fixture 已归零；`segmented-cross-cutter` 的 source-shape broad blocker 已归零。
- 已落地：root-open `superEdge` member classifier。若 member 已被 FreeCAD `findSuperEdgesUpdateFirst()` 置为 `iteration = -1`，但 root open lifecycle 仍可进入 `openWireCompound`，cad-core 先把该 helper slot 从缺 `buildClosedWire()` Remove-source、removed-target evidence 或 current-member 顶点复用失败中分流出来，再由 root-open current-member producer ledger 接管；若同 source lineage 已有 strict sidecar，producer identity 的 `source_edge_info_index` 指向该 sidecar，`current_member_edge_info_index` 继续保留当前 member。
- 已落地：root-open current-member producer ledger。root-open current-member 已按 FreeCAD open root `first->superEdge` -> `openWireCompound` 路径写入 covered/current/non-current member ledger，并构造 root producer wire；source-shape gate 可接受 open-root producer evidence，而不伪造 `buildClosedWire()` sidecar。当前重点 fixture 的 `CurrentMemberRootOpenProducerNotReady`、`CurrentMemberSidecarGeometryMismatch`、`CurrentMemberChildWireIdentityNotReady` 与 `CurrentMemberMissingSidecarEvidence` 已归零。
- 已落地：multi-member pending suppression 收敛。root-open current-member 的 sibling member 若已由同请求 openWireCompound source-edge producer child 输出，即可作为 child ownership complete 证据抑制；该路径不直接输出 multi-member root，也不在 `getOpenWires()` 输出端裁剪 sibling。当前重点 fixture 的 `MultiMemberRootPendingSuppression` 已归零。
- 已落地：foreign evidence 子集分流。foreign `aHistory->Remove(info.edge)` source 仍保留为 `ForeignAHistorySourceLineage`；若同 source lineage 已存在 strict Remove sidecar，则 blocker 收敛为 `SameSourceSidecarSourceShapeIdentityNotReady`，且 producer identity 的 `source_edge_info_index` 指向该 strict sidecar，等待同源 sidecar 的 source-shape producer identity。
- 已落地：同源 sidecar source-shape 分流。若同 source lineage strict sidecar 已经具备 source-shaped output，但该 curve 不匹配也不包含当前 result edge，blocker 进一步收敛为 `SameSourceSidecarGeometryMismatch`；`source_edge_info_index` 仍指向该 sidecar，避免把几何 ownership mismatch 继续混在 identity-not-ready 中。

- 已落地：split-fragment source-shaped producer 与 final grouped `noOriginal` gate 对齐。当前重点 fixture 的 `ForeignAHistorySourceGeometryMismatch`、`SameSourceSidecarGeometryMismatch`、`LiveResetSourceShapeWouldPurgeOriginal` 与 `CurrentMemberSourceShapeWouldPurgeOriginal` 已归零，`open_wire_compound_legacy_helper_shape_wire_info_count == 0`。

## 4. M2S 切片：source-shape / child-wire identity gate

动作：

1. 给 source edge / current member child wire 增加 identity readiness 判断。
2. 判断必须同时检查：
   - same TShape，或
   - source vertex identity 完整，且
   - child ownership complete，且
   - purge bridge 不会改变输出数量。
3. 对 member-suppressed current-member，producer 顶点必须已由 child-wire ledger 覆盖；root-open current-member 可使用 FreeCAD `wireData->Add(current->shape(...))` 对应的 input `EdgeInfo::edge` 顶点作为请求内 producer ledger，若仍会引入新顶点，继续停在 `SourceShapeMemberVertexIdentityNotReady`。
4. 把不满足的条目按 lifecycle 标记为 `SourceShapeIdentityNotReady` 或 `SourceShapeMemberVertexIdentityNotReady`。

验收：

```text
result_wire_producer_unknown_invariant_count == 0
result_wire_producer_ledger_entries[*].state/blocker 覆盖 source-shape gate
```
