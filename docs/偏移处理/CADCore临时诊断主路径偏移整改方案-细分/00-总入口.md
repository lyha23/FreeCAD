## 推进顺序

1. 持续执行 M0，防止新增几何形态 fallback。
2. 保持 M1 收口状态，不再为了清零 blocker 放宽 FreeCAD `idxVertex` / `stackPos` 或 owner 生命周期约束。
3. 先推进 M3，把 generated result-wire identity 从 `generatedOpenExportShapeForSketchInternals()` 迁到真实 `EdgeInfo` / `WireInfo` / `aHistory` 来源。
4. 再推进 M2，把 `getOpenWires()` 的 child-wire 入口收敛到真实 producer wire，并删除 `purgeAsOriginalOpenEdge` 临时 bridge。
5. 推进 M4，把 WireJoiner 元素级 history 接入 topo，使 `NamedShape` / `ElementMap` 消费正式 `MapperHistory(aHistory)`。
6. 用 M5 / M6 保护已完成主路径清理，禁止失败回流到 FaceMaker face-count 规则、Sketch result-wire 推理或 ReferenceShadow 泛化恢复。
7. 用 M7 固定 fixture 与 oracle 归因，不让失败回流成 executor 特判。
