## 拆分结论

原整改方案已经不是单一 feature 修复，而是 `WireJoiner + FaceMaker + topo history + Sketch InternalShape + ReferenceShadow + fixture/oracle` 的组合纠偏工程。

继续在一篇文档里追加“阶段推进”，会让实现难点混在一起：

- WireJoiner 身份账本缺口。
- `openWireCompound` 导出切换。
- generated result-wire 过渡来源删除。
- `MapperHistory(aHistory)` 接入 topo。
- 已完成 FaceMaker / ReferenceShadow 项的回归守护。
- fixture 失败归因。

本目录把总方案拆成可验收 milestone。每个 milestone 只回答一层责任：这一层负责什么、不能做什么、失败时应该归到哪一层、完成时看什么证据。

## 当前主判断

已完成的偏移整改：

- bounded-face classifier 已从 WireJoiner final export state 断开。
- copied result-wire graph 已从 `SketchInternalBuilder` 输出端断开。
- `getOpenWires(noOriginal)` 已删除 endpoint-touch / boundary-touch / same-coordinate 几何旁路。
- FaceMakerBuildFace topology switch 已移出主路径。
- raw/internal 几何合成 generated/split/deleted history 已从 `NamedShape.history` 主路径删除。
- ReferenceShadow 恢复已收窄到单 subshape 证据通道。

仍未完成的核心风险：

- `generatedOpenExportShapeForSketchInternals()` 仍是 generated open-export 过渡来源。
- `purgeAsOriginalOpenEdge` 仍是 original open edge 与 split/result edge 的临时 identity bridge。
- `openWireCompound` child-wire 账本已存在，但直接切成输出主路径会导致 original open edge 泄漏和 T-junction result-wire 丢失。
- WireJoiner 的完整 `aHistory` / `myShapesToReturn` / 元素级 `MapperHistory(aHistory)` 还没有完全进入 topo。

## 推进顺序

1. 先执行 M0，确保不再新增几何形态规则。
2. 推进 M1，把 FreeCAD `EdgeInfo` / `WireInfo` 生命周期补完整。
3. 推进 M2，把 `getOpenWires()` 切到真实 `openWireCompound` child-wire 边界。
4. 推进 M3，逐类删除 generated result-wire 过渡来源。
5. 推进 M4，把 WireJoiner 元素级 history 接入 topo。
6. 用 M5 / M6 保护已完成主路径清理。
7. 用 M7 固定 fixture 与 oracle 归因，不让失败回流成 executor 特判。
